## 0. 이 문서가 하는 일

이 목록은 두 가지로 쓰인다.

1. **수집 대상 목록** — 관리자가 "수집 관리" 화면의 입력칸에 붙여넣을 IMSLP 작품 페이지 주소 50줄 (F7).
2. **한국어 별칭 사전의 첫 시드** — 수집이 끝난 뒤 관리자가 곡마다 채워야 하는 한국어 대표 제목·별칭·난이도·악장 안내를 미리 적어 둔 것 (F5). 개발자가 CSV/시드 데이터로 바꿔 관리자 입력을 대신할 수 있다.

### 표를 다룰 때 지킬 것 (개발자용)

- 마크다운 표 1개, 50행. 열 순서를 바꾸지 않는다.
- **별칭 열만** 쉼표(,)가 구분자다. 다른 열의 쉼표(예: `Nocturnes, Op.9`)는 제목의 일부이므로 CSV 변환 시 셀을 큰따옴표로 감싼다.
- 비고 열 안에서는 항목 구분에 가운뎃점(·)을 쓴다.
- URL 은 `https://imslp.org/wiki/{제목}_({성,_이름})` 형식 그대로 적었다. **비ASCII 문자(é, ü, ä, ą)·아포스트로피(')·슬래시(/)·쉼표(,)가 들어간 주소가 있다.** 수집 화면의 "주소 형식 확인"이 이런 문자를 형식 오류로 판정하면 안 된다 (§4 미결 1).
- 작품번호 열이 "(없음)"인 곡은 작품번호를 비워 둔다.

곡집(소나타·모음곡·연습곡집)은 **전곡 기준**으로 매기고, 특정 악장·곡이 더 쉽거나 어려우면 비고에 적었다. 관리자는 곡 상세의 "악장 페이지 안내"에 이 정보를 옮겨 적는다.

## 5. 별칭을 적을 때의 규칙 (관리자·시드 변환 공통)

01 문서 F2의 검색 규칙(대소문자·공백·마침표 무시, 부분 일치)을 전제로 한다.

1. **띄어쓰기만 다른 변형은 하나만 넣는다.** "월광 소나타"와 "월광소나타"는 검색이 공백을 무시하므로 같다. 표에 둘 다 있는 경우는 사용자 검수 편의용이며, 시드 변환 때 중복 제거해도 된다.
2. **외래어 표기 변형은 따로 넣는다.** "트로이메라이/트로이머라이", "부르크뮐러/부르그뮐러"는 글자가 다르므로 별개 별칭이다.
3. **영문 별칭은 악센트 있는 것과 없는 것을 둘 다 넣는다.** "Für Elise"와 "Fur Elise". 검색이 악센트를 무시하게 될지는 senior-dev 결정(§6 미결 2) — 정해지면 한쪽을 지운다.
4. **곡집 안의 유명 개별곡 이름은 곡집의 별칭으로 넣는다.** "강아지 왈츠" → 왈츠 Op.64. 사용자는 곡집 상세에서 "1번, 3쪽"이라는 안내를 보고 전곡 PDF를 받는다 (1차는 악장 분할 없음 — 00 문서 §7).
5. **다른 곡과 겹치는 별칭은 그대로 둔다.** "아라베스크"(부르크뮐러·드뷔시), "발라드"(부르크뮐러·쇼팽), "녹턴"(쇼팽 두 곡). 검색 결과에 여러 곡이 뜨는 것이 맞는 동작이며, 관리자 화면은 경고만 보여준다 (01 문서 F5-2).
6. **다른 편성의 유명곡 이름은 넣지 않는다.** "헝가리 무곡"을 헝가리 광시곡 별칭에 넣으면 잘못된 곡을 받게 된다.
7. **작곡가 이름 변형은 곡 별칭이 아니라 작곡가 별칭에 넣는다** (§2). "차이코프스키 사계"는 작곡가 별칭 "차이코프스키" + 곡 별칭 "사계"의 조합으로 검색된다.
