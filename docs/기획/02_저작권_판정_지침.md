# 한국 기준 저작권 판정 지침 (1차)

> 작성일: 2026-09-05 (메인 세션). 관리자가 판본마다 "한국 기준 판정"을 입력할 때 쓰는 규칙이다. 법률 자문이 아니며, 불명확하면 보수적으로(다운로드 막음) 간다.

## 판정 값 (판본 단위)
| 값 | 의미 | 사용자 화면 |
|---|---|---|
| `FREE` | 한국에서 자유 이용 가능 | 초록 뱃지 "한국에서 자유 이용 가능" + 다운로드 버튼 |
| `RESTRICTED` | 한국에서 보호 중(비PD) | 회색 뱃지 "한국에서 이용 제한" + IMSLP 원본 링크만 |
| `UNKNOWN` | 확인 중 | 노란 뱃지 "저작권 확인 중" + IMSLP 원본 링크만 |

## 규칙
1. **작곡가**: 사망 연도 + 70년 < 올해 이면 통과. (한국 저작권법: 저작자 사후 70년. 1962년 이전 사망자는 사후 50년 규정으로 이미 만료 — 결과는 같으므로 70년으로 통일 계산.)
2. **편집자·편곡자**: 판본에 편집자(Editor)나 편곡자(Arranger)가 표기돼 있으면 그 사람도 규칙 1을 통과해야 한다. 편집자 사망 연도를 모르면 `UNKNOWN`.
3. **편집자 없음·익명·출판사 명의**: 초판 출판 연도 + 70년 < 올해 이면 통과.
4. **IMSLP 표기가 CC 라이선스**(Creative Commons): 라이선스 조건대로 재배포 가능하면 `FREE` 로 두되, 판본 정보에 라이선스명과 저작자 표기를 반드시 보여준다. NC(비영리)·ND(변경금지) 조건도 그대로 표기. 우리 서비스는 무료라 NC 는 충돌하지 않는다.
5. **IMSLP 표기가 "Non-PD US/EU" 등 국가 제한**: 한국 규칙(1~3)으로 다시 계산한다. IMSLP 의 국가 표기를 그대로 믿지 않는다.
6. **손글씨 자필보(Manuscript)·필사본**: 작곡가 규칙 1만 적용.
7. 규칙 어디에도 안 들어가면 `UNKNOWN`.

## 표기 의무
- 모든 판본 상세에 "출처: IMSLP" + 원본 작품 페이지 링크 + 스캔 제공자·출판사·편집자 정보를 표시한다.
- CC 판본은 라이선스명을 함께 표시한다.

## 예시
- 베토벤(1827 사망) 월광 소나타, 편집자 Sigmund Lebert(1884 사망) 판본 → 둘 다 통과 → `FREE`
- 쇼팽(1849 사망) 녹턴, 편집자 Ignacy Paderewski(1941 사망) 판본 → 1941+70=2011 < 2026 → `FREE`
- 드뷔시(1918 사망), 편집자 불명·1970년대 출판 판본 → 출판+70=204x → `RESTRICTED` (편집 저작물 보호 가능성). 작곡가 원판(초판 1900년대) 스캔이면 `FREE`
- 라흐마니노프(1943 사망) → 2013 만료 → 원판 스캔은 `FREE`. 단 편집자 확인 필요.
