## 0. 이 문서의 범위와 용어

### 0-1. 한 줄 정의

**"한국어로 검색 → 곡 하나 → 추천 악보 1개 → 바로 PDF."**

### 0-2. 1차 범위

| 포함 | 제외 (2차 이후) |
|---|---|
| 피아노 독주곡만 | 다른 편성(성악·합창·실내악·오케스트라) |
| 비로그인 사용자: 검색·곡 상세·작곡가·다운로드 | 즐겨찾기, 별칭 제안, 판본 후기 등 로그인이 필요한 사용자 기능 |
| 관리자(ADMIN): 곡·별칭·난이도·판본·저작권 관리, 수집 운영 | 사용자 회원가입 유도, 마이페이지 확장 |
| 전곡 PDF 1개 단위 제공 | 악장별 분할 PDF (악장 페이지 안내 문구는 제공) |
| 웹(반응형) | Flutter 앱 |

### 0-3. 사용자에게 보이는 용어 (화면 전체에서 통일)

| 용어 | 뜻 | IMSLP 원어 |
|---|---|---|
| **곡** | 작품 하나. 예: 월광 소나타 | Work |
| **판본** | 한 곡에 딸린 PDF 파일 하나. 출판사·편집자·스캔이 다르면 다른 판본 | File / Edition |
| **추천 판본** | 관리자가 곡마다 1개 고른 "이걸 받으세요" 판본 | (없음 — 우리 개념) |
| **전체 악보** | 곡 전체(또는 특정 악장)를 담은 악보 | Complete Score |
| **파트보** | 한 악기 파트만 담은 악보. 피아노 독주에는 거의 없음 (용어만 예비) | Parts |
| **편곡** | 다른 편성에서 피아노로, 또는 피아노에서 다른 편성으로 옮긴 악보 | Arrangements and Transcriptions |
| **포함 범위** | 판본이 전곡을 담는지, 특정 악장만 담는지. 예: "전곡", "2악장만" | (IMSLP 섹션 구분) |
| **별칭** | 한 곡을 부르는 모든 이름. 한국 통용명·별명·원어·영어 별칭 | (Alternative Title) |
| **작품번호** | Op. / BWV / K. / D. / Hob. 등 작품 식별 번호 | Opus / Catalogue No. |
| **난이도** | 입문 / 초급 / 중급 / 고급 / 미정 (관리자 직접 입력, 자동 산정 없음) | (없음) |
| **한국 기준 저작권** | 아래 3가지 중 하나. 뱃지로 표시 | (IMSLP 표기는 별도 원문 보관) |

**한국 기준 저작권 뱃지 3종** (판본마다 하나)

| 뱃지 | 뜻 | 사용자가 할 수 있는 것 |
|---|---|---|
| **한국에서 자유 이용 가능** | 관리자가 한국 기준(저작자 사후 70년, 편집자·편곡자 권리 포함)으로 이용 가능하다고 판정 | 우리 서버에서 바로 다운로드 |
| **한국에서 이용 제한** | 한국 기준으로 아직 보호 중이거나 재배포 불가로 판정 | 다운로드 불가. IMSLP 원본 페이지 링크만 |
| **저작권 확인 중** | 관리자 판정 전 (수집 직후 기본값) | 다운로드 불가. IMSLP 원본 페이지 링크만 |

**곡의 준비 상태** (검색 결과·상세에서 사용자에게 보이는 뱃지)

| 상태 | 조건 | 표시 |
|---|---|---|
| **바로 받기 가능** | 추천 판본이 지정되어 있고, 그 판본의 PDF가 우리 서버에 있고, 뱃지가 "자유 이용 가능" | 뱃지 없음(기본), 다운로드 버튼 활성 |
| **준비 중** | 추천 판본이 없거나, 추천 판본의 PDF가 아직 없음(수집 전 / 수집 실패 / 정보만 등록) | "준비 중" 뱃지, IMSLP 링크 제공 |
| **이용 제한** | 추천 판본은 있으나 뱃지가 "이용 제한" 또는 "확인 중" | "한국에서 이용 제한" 또는 "저작권 확인 중" 뱃지, IMSLP 링크 제공 |

## 2. 사용자 흐름 — 일반 사용자 (비로그인)

### F1. 홈

1. 사용자가 서비스 주소로 들어온다 → **홈** 화면. 로그인 요구 없음.
2. 홈에는 다음이 위에서 아래 순서로 보인다.
   - 서비스 이름과 한 줄 설명("한국어로 검색하고 바로 받는 피아노 악보")
   - **검색창 1개** (자리 문구: "곡 이름, 작곡가, 작품번호로 찾기 — 예: 월광, 쇼팽 녹턴, K.545"). 화면이 열리면 검색창에 커서가 가 있다.
   - **인기곡** 10개: 누적 다운로드 수가 많은 순. 다운로드 기록이 없는 초기에는 최근 등록순. 각 항목은 한국어 제목 · 작곡가 한글 · 난이도. 누르면 **곡 상세**.
   - **작곡가 바로가기**: 공개된 곡이 1개 이상 있는 작곡가 중 곡 수가 많은 순 8명 (한글 표기). 누르면 **작곡가 상세**. 옆에 "모든 작곡가 보기" → **작곡가 목록**.
3. 검색창에 글자를 넣고 Enter 또는 검색 버튼 → **검색 결과** 화면으로 이동.
4. 빈 검색어(공백만)로 Enter → 이동하지 않고 검색창 흔들림 등 가벼운 표시만. 오류 문구 없음.

### F2. 검색

1. **검색 결과** 화면 상단에 검색창이 그대로 있고, 입력했던 검색어가 채워져 있다. 검색어를 고쳐 다시 검색할 수 있다.
2. 결과 화면 주소에 검색어가 담겨 있어, 주소를 복사해 다른 사람에게 보내면 같은 결과가 보인다. 브라우저 뒤로 가기를 누르면 직전 화면(홈 또는 이전 검색)으로 돌아간다.
3. **무엇으로 찾아지나** — 검색어가 다음 중 어디에라도 **부분 일치**하면 결과에 나온다.
   - 곡의 한국어 대표 제목 ("월광 소나타")
   - 곡의 별칭 전부 ("월광", "Moonlight Sonata", "엘리제", "Für Elise")
   - 곡의 원어 제목 ("Piano Sonata No.14")
   - 작곡가 한글 표기("쇼팽", "베토벤"), 작곡가 원어 표기("Chopin", "Beethoven, Ludwig van" — 성·이름 어느 순서로 쳐도), 작곡가 별칭("차이코프스키" / "차이콥스키")
   - 작품번호 ("Op.27 No.2", "BWV 846", "K.545")
4. **일치 규칙**
   - 대소문자 무시. 공백 무시 ("op27no2" = "Op. 27 No. 2", "BWV846" = "BWV 846").
   - 작품번호 표기의 마침표·쉼표 유무 무시 ("Op 27, No 2" = "Op.27 No.2").
   - 검색어를 공백으로 나눠 **모든 단어가 각각** (곡명·별칭·작곡가·작품번호) 어딘가에 걸려야 한다. "쇼팽 녹턴" → 작곡가가 쇼팽이면서 곡명/별칭에 "녹턴"이 있는 곡 전부. "베토벤 월광" → 월광 소나타 1건.
   - 초성 검색("ㅇㄹㅈ")은 1차 포함 여부 미결 (§8-4).
5. **결과 화면 구성**
   - **작곡가 일치 영역** (검색어가 작곡가 이름에 걸릴 때만 맨 위에): "작곡가: 쇼팽 (Frédéric Chopin) — 곡 24개 →" 카드. 누르면 **작곡가 상세**.
   - **곡 목록**: 한 항목에 보이는 정보
     - 한국어 대표 제목 (굵게)
     - 원어 제목
     - 작곡가 한글 표기 (원어 표기)
     - 작품번호
     - 난이도 (입문/초급/중급/고급, 미정이면 "난이도 미정")
     - 추천 판본 쪽수 ("12쪽") — 추천 판본이 없으면 표시 안 함
     - 추천 판본 첫 페이지 축소 이미지 (있을 때만)
     - 준비 상태 뱃지 ("준비 중" / "한국에서 이용 제한" / "저작권 확인 중"). 바로 받기 가능한 곡은 뱃지 없음
     - 검색어가 별칭에 걸렸다면 "'월광'으로 찾음"처럼 어떤 이름으로 걸렸는지 한 줄 (같은 곡이 왜 나왔는지 사용자가 이해하도록)
   - 항목을 누르면 **곡 상세**.
   - 결과 건수 표시 ("'녹턴' 검색 결과 21곡").
   - **정렬**: 기본은 일치도 순 (한국어 대표 제목·별칭에 정확히 일치 → 앞부분 일치 → 그 외 부분 일치), 같으면 누적 다운로드 수 많은 순.
   - **필터** (결과 위쪽, 누르면 즉시 반영, 여러 개 동시 가능)
     - 난이도: 입문 / 초급 / 중급 / 고급 (복수 선택). 미정 곡은 필터를 걸면 빠진다.
     - 쪽수: 10쪽 이하 / 11~20쪽 / 21쪽 이상 (추천 판본 기준. 추천 판본 없는 곡은 쪽수 필터 걸면 빠진다)
     - 바로 받기 가능한 곡만 보기 (체크)
   - 20개씩 나누어 보여주고, 아래에 페이지 이동. 필터·페이지 상태도 주소에 담겨 공유·뒤로가기가 된다.
6. **숨김 처리된 곡**(관리자가 숨김)은 검색·인기곡·작곡가 목록 어디에도 나오지 않는다. 주소로 직접 들어가도 "찾을 수 없는 페이지".

### F3. 곡 상세

1. 검색 결과·인기곡·작곡가 페이지에서 곡을 누르면 **곡 상세**. 주소를 공유하면 같은 화면이 보인다.
2. **곡 정보 영역** (맨 위)
   - 한국어 대표 제목 (제목 크기)
   - 원어 제목
   - 작곡가 한글 표기 (원어 표기) — 누르면 **작곡가 상세**
   - 작품번호
   - 난이도 뱃지
   - "이렇게도 불러요: 월광, Moonlight Sonata, 월광 소나타 14번" — 별칭 나열 (없으면 줄 자체 생략)
   - 작곡 연도, 조성, 악장 구성 — 있는 것만 표시
   - 악장 페이지 안내 (관리자가 적었을 때만): "1악장 1쪽 · 2악장 6쪽 · 3악장 9쪽 (추천 판본 기준)"
3. **추천 판본 카드** (화면의 주인공, 크게)
   - "추천 판본" 라벨
   - **첫 페이지 미리보기 이미지** — 누르면 크게 보기(화면 위에 띄움, 닫기 버튼/바깥 클릭으로 닫힘). 이미지가 아직 없으면 회색 자리에 "미리보기 준비 중"
   - 판본 종류 (전체 악보 / 파트보 / 편곡) + 포함 범위 (전곡 / N악장만)
   - **쪽수**, **파일 크기** (예: "12쪽 · 2.4MB")
   - 판본 정보: 출판사, 출판 연도, 편집자, 스캔 제공자 — 있는 것만
   - 한국 기준 저작권 뱃지 + IMSLP 원문 표기 한 줄 (예: "IMSLP 표기: Public Domain")
   - CC 라이선스 판본이면 라이선스 이름과 저작자 표기 한 줄 (예: "CC BY-SA 4.0 · 편집: ○○○")
   - 출처: "출처: IMSLP — 원본 페이지 보기" (새 탭). IMSLP 파일 페이지 링크도 함께
   - **다운로드 버튼** ("PDF 받기 · 2.4MB"): 누르면 즉시 파일이 내려온다. 면책·대기·확인 창 없음. 버튼 1번 = PDF 1개
     - 파일 이름: `작곡가 한글 - 한국어 대표 제목 (작품번호).pdf` 예: `베토벤 - 월광 소나타 (Op.27 No.2).pdf` (형식 확정은 §8-9)
     - 다운로드가 시작되면 누적 다운로드 수가 1 올라간다 (인기곡 순위에 반영)
     - 파일 크기가 **20MB 이상**이면 버튼 옆에 "파일이 큽니다 (25MB). 모바일 데이터에 주의하세요" 한 줄. 그래도 클릭 1번으로 받는다 (확인 창 띄우지 않음)
4. **"다른 판본 보기 (N개)"** — 기본 접힘. 펼치면 추천 판본을 뺀 나머지 판본 목록. 한 줄에
   - 판본 종류 · 포함 범위
   - 쪽수 · 파일 크기 (파일 없으면 "파일 없음")
   - 출판사 / 편집자 / 연도
   - 한국 기준 저작권 뱃지
   - 행 오른쪽 버튼: 바로 받기 가능하면 "PDF 받기", 아니면 "IMSLP에서 보기"
   - 첫 페이지 미리보기는 행에 작게 (있을 때만), 누르면 크게 보기
   - 다른 판본이 0개면 이 영역 자체를 표시하지 않는다
5. 화면 아래 "같은 작곡가의 다른 곡" 5개 (다운로드 수 순) → 누르면 그 곡 상세. 없으면 영역 생략.

### F4. 작곡가

**작곡가 목록**
1. 홈 "모든 작곡가 보기" 또는 헤더 "작곡가" 메뉴 → **작곡가 목록**.
2. 공개된 곡이 1개 이상 있는 작곡가만, 한글 표기 가나다순. 한 항목: 한글 표기 · 원어 표기 · 생몰년 · 곡 수.
3. 누르면 **작곡가 상세**.

**작곡가 상세**
1. 상단: 한글 표기 (제목), 원어 표기, 생몰년, 국적(있으면), 검색용 별칭(있으면 "차이콥스키라고도 씁니다"), IMSLP 작곡가 페이지 링크(새 탭).
2. **곡 목록**: 이 작곡가의 공개 곡 전부. 항목 정보는 검색 결과와 동일 (한국어 제목, 원어 제목, 작품번호, 난이도, 쪽수, 상태 뱃지). 작곡가 이름은 생략.
3. 정렬: 기본 누적 다운로드 수 순. "작품번호 순"으로 바꿀 수 있다.
4. 필터: 검색 결과와 같은 난이도 · 쪽수 · 바로 받기 가능만.
5. 20개씩 페이지 이동.

### F8. 공통 틀

- **헤더**: 서비스 이름(로고, 누르면 홈) · 작은 검색창(홈 이외 모든 일반 화면에서, 입력 후 Enter → 검색 결과) · "작곡가" 메뉴 · 오른쪽에 로그인 상태 표시
  - 비로그인: "로그인" 버튼 (관리자 진입용. 노출 여부는 §8-3)
  - 로그인(ADMIN): "관리" 메뉴 + 닉네임 + 로그아웃
  - 로그인(USER): 닉네임 + 로그아웃 (1차에는 USER 전용 기능이 없다)
  - 기존 "커뮤니티" "채팅" 메뉴: 1차 범위 밖. 처리 방식은 §8-2
- **푸터**: "악보 출처: IMSLP (imslp.org)" · "저작권 안내: 각 악보의 한국 기준 이용 가능 여부는 판본별로 표시합니다. 판정에 이견이 있으면 알려주세요 (연락처)" · 서비스 이름
- **찾을 수 없는 페이지** (기존 화면 유지): 문구 "찾을 수 없는 페이지예요" + "홈으로" 버튼 + 검색창

## 3. 사용자 흐름 — 관리자

### 공통: 관리자 진입

1. 헤더 "로그인" → 기존 **로그인** 화면 → 로그인 성공 시 **원래 보던 화면**으로 돌아온다 (홈에서 눌렀으면 홈).
2. ADMIN 역할이면 헤더에 "관리" 메뉴가 생긴다 → **관리 홈**.
3. USER 역할이 관리 화면 주소로 직접 들어오면 → "관리자만 들어갈 수 있어요" 안내 + "홈으로" 버튼. 관리 메뉴는 보이지 않는다.
4. 비로그인이 관리 화면 주소로 직접 들어오면 → 로그인 화면으로. 로그인 후 원래 가려던 관리 화면으로.
5. 관리 화면 안에서 세션이 끊기면(오래 방치 등) → 저장 시도 시 "로그인이 풀렸어요. 다시 로그인해 주세요" + 로그인 화면으로. 작성 중이던 내용은 잃을 수 있음을 안내.

### 관리 홈 (대시보드)

- 숫자 카드: 전체 곡 수 · 바로 받기 가능 곡 수 · 준비 중 곡 수 · 보완 필요 곡 수(§F7-6 참고) · 저작권 확인 중 판본 수 · 이번 달 다운로드 수
- 바로가기: 작곡가 관리 / 곡 관리 / 저작권 판정 대기함 / 수집 관리
- "최근 수집 작업" 1건 요약: 상태(진행 중/완료/중지됨/실패) · 진행 N/M · 시작 시각 → 누르면 **수집 진행/결과** 화면
- 수집이 진행 중이면 관리 화면 어디에서나 상단에 얇은 띠 "수집 진행 중 12/50 — 보기"가 보인다.

### F5. 작곡가·곡·별칭·난이도 관리

**작곡가 관리**
1. 관리 홈 → **작곡가 목록(관리)**: 이름 검색, 곡 수, 한글 표기 유무. "새 작곡가" 버튼.
2. **작곡가 등록/수정** 입력 항목
   - 한글 표기 (필수) — 예: 베토벤
   - 원어 표기 (필수) — 예: Beethoven, Ludwig van
   - 검색용 별칭 (여러 개, 선택) — 예: 루트비히 판 베토벤
   - 생년·몰년 (선택. 저작권 판정 근거로 쓰이니 입력 권장 문구 표시)
   - 국적 (선택)
   - IMSLP 작곡가 페이지 링크 (선택)
3. 저장 → 목록으로, "저장했어요" 알림. 같은 원어 표기가 이미 있으면 "이미 등록된 작곡가예요 — 보기" 안내로 중복 막음.
4. 삭제: 곡이 1개라도 있으면 삭제 불가 안내("곡 12개가 있어 삭제할 수 없어요. 곡을 먼저 옮기거나 지우세요").

**곡 관리**
1. 관리 홈 → **곡 목록(관리)**: 검색창(사용자 검색과 같은 규칙) + 필터
   - 상태: 바로 받기 가능 / 준비 중 / 이용 제한 / 저작권 확인 중 / **보완 필요** / 숨김
   - 작곡가
   - 난이도(미정 포함)
   - 한 항목: 한국어 제목(없으면 원어 제목을 회색으로) · 작곡가 · 작품번호 · 난이도 · 판본 수 · 추천 판본 유무 · 상태 · 마지막 수정일
   - "새 곡" 버튼 (수집을 안 거치고 직접 등록할 때)
2. **곡 등록/수정** 화면 — 위쪽은 곡 정보, 아래쪽은 판본 목록(F6)
   - 작곡가 (필수, 목록에서 고르기. 없으면 "새 작곡가 등록" 바로가기)
   - 한국어 대표 제목 (필수 — 비어 있으면 저장은 되지만 상태가 "보완 필요")
   - 원어 제목 (필수)
   - 작품번호 (여러 개 가능. 예: "Op.27 No.2", "WoO 59")
   - 별칭 목록: 한 줄에 하나씩 추가/삭제. 같은 곡 안 중복은 막고, **다른 곡과 같은 별칭은 허용하되** "'녹턴'은 다른 곡 20개에도 있어요" 경고만 보여준다 (사용자는 검색 결과에서 여러 곡을 본다)
   - 난이도: 입문 / 초급 / 중급 / 고급 / 미정 (기본 미정)
   - 작곡 연도, 조성, 악장 구성 (선택)
   - 악장 페이지 안내 (선택, 자유 문장. 예: "1악장 1쪽 · 2악장 6쪽")
   - IMSLP 작품 페이지 링크 (수집으로 만든 곡은 자동 채움, 직접 등록이면 선택)
   - 숨김 여부 (기본: 보임). 숨기면 사용자 화면 어디에도 안 나온다
   - 저장 → 같은 화면에 머물며 "저장했어요". "사용자 화면에서 보기" 링크(새 탭)
3. **보완 필요** 판정 규칙 (관리자에게만 보이는 표시): 한국어 대표 제목이 비었거나, 별칭이 0개이거나, 난이도가 미정이거나, 추천 판본이 없으면 "보완 필요". 곡 편집 화면 상단에 "빠진 것: 한국어 제목, 난이도" 식으로 항목을 나열한다.
4. 곡 삭제: 판본이 있으면 "판본 3개와 파일이 함께 지워져요" 확인 창 → 확인 시 삭제. 다운로드 기록이 있는 곡은 삭제 대신 숨김을 권장하는 문구.

### F6. 판본 관리 (곡 편집 화면 아래쪽)

1. **판본 목록**: 한 행에 종류·포함 범위 · 쪽수 · 크기 · 출판사/편집자/연도 · 파일 유무 · 한국 기준 뱃지 · "추천" 표시 · 다운로드 수. 행 오른쪽에 "수정" "추천으로 지정" "파일 받아오기"(파일 없고 IMSLP 링크 있을 때) "삭제".
2. **판본 추가/수정** 입력 항목
   - PDF 파일: 파일 선택 → 올리면 **쪽수·파일 크기·첫 페이지 미리보기가 자동으로 채워진다** (쪽수는 수정 가능). PDF가 아니거나 상한(§8-6)을 넘으면 즉시 거부 안내. 이미 파일이 있으면 "교체" (교체 시 미리보기·쪽수·크기 다시 채움)
   - 판본 종류 (필수): 전체 악보 / 파트보 / 편곡
   - 포함 범위 (필수): 전곡 / 특정 악장(악장 번호 입력)
   - 출판사, 출판 연도, 플레이트 번호, 편집자, 스캔 제공자 (선택)
   - IMSLP 파일 페이지 링크 (수집이면 자동)
   - IMSLP 저작권 표기 원문 (수집이면 자동. 예: "Public Domain", "Creative Commons Attribution-ShareAlike 4.0")
   - **한국 기준 저작권 판정** (필수): 자유 이용 가능 / 이용 제한 / 확인 중 (기본 "확인 중")
   - 판정 메모 (판정을 "자유 이용 가능" 또는 "이용 제한"으로 바꿀 때 **필수**): 근거를 적는다. 예: "작곡가 1827 사망, 편집자 1913 사망 → 사후 70년 경과". 화면에 작곡가 몰년을 자동으로 보여준다 (등록돼 있을 때)
   - CC 라이선스라면 라이선스 이름 + 표기할 저작자 (선택, 사용자 화면에 노출)
3. **추천으로 지정**: 곡당 1개. 다른 판본이 추천이면 자동 해제되고 "추천 판본을 ○○에서 △△로 바꿨어요" 알림. PDF 파일이 없는 판본은 지정 불가 ("파일이 없어 추천으로 지정할 수 없어요"). 저작권이 "확인 중"/"이용 제한"인 판본은 지정은 되지만 경고("이 판본은 사용자에게 다운로드가 열리지 않아요").
4. **추천 후보 제안**: 수집으로 만든 곡은 시스템이 "전체 악보 · 전곡 · IMSLP 다운로드 수 최다" 판본을 "추천 후보"로 표시해 준다. 관리자는 "이 후보를 추천으로 지정" 한 번에 확정. 후보는 사용자에게 보이지 않는다.
5. 판본 삭제: 추천 판본이면 "추천이 해제됩니다" 확인. 다운로드 기록이 있으면 경고 후 삭제 가능.

**저작권 판정 대기함**
1. 관리 홈 → **저작권 판정 대기함**: 판정이 "확인 중"인 판본 전부. 한 행에 곡 · 작곡가(몰년) · 판본 종류 · 편집자 · IMSLP 표기 원문 · IMSLP 링크.
2. 행마다 바로 "자유 이용 가능" / "이용 제한" 버튼 + 메모 입력. 저장하면 행이 대기함에서 사라진다.
3. 여러 행 선택 → 같은 판정·메모 일괄 적용 (예: 같은 작곡가의 PD 스캔 20개).

### F7. 수집 운영 (관리자 관점)

**수집이 하는 일 / 관리자가 하는 일** (사용자에게 보이는 결과 기준)

| 수집이 자동으로 채우는 것 | 관리자가 채우는 것 |
|---|---|
| 원어 제목, 작곡가 원어 표기(없으면 작곡가 새로 생성), 작품번호, IMSLP에 적힌 영문 별칭, 작곡 연도·조성·악장 구성, IMSLP 작품 페이지 링크 | 한국어 대표 제목, 한국어 별칭, 작곡가 **한글 표기**(작곡가마다 최초 1회), 난이도, 악장 페이지 안내 |
| 작품 페이지의 **모든 판본 정보** (종류, 포함 범위, 쪽수, 크기, 출판사, 연도, 편집자, 스캔 제공자, IMSLP 저작권 표기, IMSLP 다운로드 수, 파일 페이지 링크) | 한국 기준 저작권 판정 + 메모 |
| **PDF 파일은 "전체 악보" 중 IMSLP 다운로드 수 상위 2개만** 실제로 받아온다 (추천 1 + 대체 1). 나머지 판본은 정보만 | 추천 판본 확정 (후보를 확인만 하면 됨). 그 외 판본의 파일이 필요하면 "파일 받아오기" 개별 실행 |
| 받아온 PDF의 첫 페이지 미리보기 | — |

**흐름**

1. 관리 홈 → **수집 관리**. 화면은 위에 "수집 대상 등록", 아래에 "수집 작업 목록"(최근 순).
2. **수집 대상 등록**
   - 큰 입력칸에 IMSLP 작품 페이지 주소를 **한 줄에 하나씩** 붙여넣는다 (예: `https://imslp.org/wiki/Piano_Sonata_No.14,_Op.27_No.2_(Beethoven,_Ludwig_van)`). 파일 하나로 올리는 방식은 1차에 없다.
   - "확인" 버튼 → 줄마다 판정 표가 뜬다
     - 정상: "수집 예정"
     - 주소 형식이 IMSLP 작품 페이지가 아님: "주소 형식 오류" (수집 대상에서 제외)
     - 이미 우리 서비스에 같은 IMSLP 링크로 등록된 곡: "이미 있음 — 건너뜀" (옆에 "정보만 다시 가져오기" 체크를 켜면 판본 정보를 갱신하되 **이미 받은 파일은 다시 받지 않는다**)
     - 같은 주소가 목록 안에 중복: 하나만 남기고 "중복 제거"
   - 표 아래 요약: "수집 예정 48건 · 건너뜀 2건 · 오류 1건 · 예상 소요 약 1시간 10분"
   - **예상 시간 안내 문구 (고정 표시)**: "IMSLP 서버에 부담을 주지 않도록 요청 사이에 2초 이상 쉬며 천천히 가져옵니다. 곡당 보통 1~2분, 파일이 크면 더 걸립니다. 화면을 닫아도 수집은 계속됩니다."
3. **"수집 시작"** 버튼 → 수집 작업이 만들어지고 **수집 진행** 화면으로 이동.
   - 이미 진행 중인 작업이 있으면 "수집 시작" 버튼은 비활성 + "진행 중인 수집이 끝나면 시작할 수 있어요 — 보기". 동시에 하나만 돈다.
4. **수집 진행** 화면
   - 상단 진행 막대: "12 / 50 완료 · 성공 11 · 실패 1 · 남은 예상 시간 약 45분"
   - "지금 처리 중: Nocturne in E-flat major, Op.9 No.2 — 판본 정보 읽는 중 / 파일 받는 중 (2/2)"
   - 항목 목록: 순서 · IMSLP 주소 · 상태(대기 / 처리 중 / 성공 / 실패 / 건너뜀) · 결과 요약(성공: "판본 14개, 파일 2개 받음 → 곡 보기" / 실패: 사유)
   - 화면은 **10초마다 자동 갱신**. "새로고침" 버튼도 있다.
   - **"중지"** 버튼: 지금 처리 중인 곡은 끝까지 마치고 멈춘다. 남은 항목은 "대기"로 남는다. 상태가 "중지됨"으로 바뀌고 **"이어서 시작"** 버튼이 생긴다.
   - 화면을 떠났다가 (브라우저를 닫았다가) 다시 들어와도 같은 현황이 보인다.
5. **수집 결과** (작업이 끝나면 같은 화면이 결과 모드로)
   - 요약: "총 50건 — 성공 46 · 실패 3 · 건너뜀 1 · 걸린 시간 1시간 3분"
   - 실패 항목은 사유와 함께 위로 모아 보여주고, **"실패한 것만 다시 시도"** 버튼 (새 작업으로 만들어져 다시 §4 진행 흐름). 실패 사유 종류:
     - "IMSLP에 그 페이지가 없어요" (주소 오타·이동)
     - "작품 페이지에 PDF 판본이 없어요" (정보만 등록되고 곡은 "준비 중")
     - "파일을 받다가 끊겼어요" (판본 정보는 등록됨, 파일만 없음 → 곡 편집에서 "파일 받아오기"로 개별 재시도 가능)
     - "IMSLP가 응답하지 않아요" (아래 예외 §4 참고)
     - "피아노 독주곡이 아닌 것 같아요" — 편성 정보가 피아노 독주가 아니면 **등록은 하되 숨김 상태**로 만들고 사유에 표시. 관리자가 확인 후 숨김 해제
   - 성공 항목: "→ 곡 보기" 를 누르면 **곡 편집** 화면. 수집으로 만든 곡은 한국어 제목·별칭·난이도가 비어 있으므로 모두 **"보완 필요"** 상태다. 사용자 검색에는 원어 제목·작곡가·작품번호로는 이미 찾히지만 (숨김이 아니므로) "준비 중"/"저작권 확인 중" 뱃지로 보인다.
6. **수집 후 관리자 마무리 흐름** (곡 1개당)
   1. 곡 관리 → 필터 "보완 필요" → 곡 편집
   2. 한국어 대표 제목·별칭·난이도 입력 (작곡가 한글 표기가 비어 있으면 상단 경고 "작곡가 한글 표기가 없어요 → 작곡가 편집")
   3. 판본 목록에서 "추천 후보" 확인 → "추천으로 지정"
   4. 저작권 판정 (곡 편집에서 판본별로 하거나, 대기함에서 일괄)
   5. 저장 → 곡 상태가 "바로 받기 가능"으로 바뀌고 사용자 화면에 다운로드 버튼이 열린다

## 6. 인수 조건 (qa 체크리스트)

### 홈 / 공통
- [ ] 로그인하지 않은 상태로 서비스 주소에 들어가면 홈이 열리고, 로그인 요구가 없다.
- [ ] 홈에 검색창 1개, 인기곡 10개(다운로드 수 순, 기록 없으면 최근 등록순), 작곡가 8명(곡 수 순)이 보인다.
- [ ] 홈이 열리면 검색창에 바로 입력할 수 있다 (커서가 검색창에 있다).
- [ ] 홈 인기곡 항목을 누르면 그 곡의 상세로 이동한다.
- [ ] 홈 작곡가 항목을 누르면 그 작곡가 상세로, "모든 작곡가 보기"를 누르면 작곡가 목록으로 이동한다.
- [ ] 홈 이외의 일반 화면(검색 결과·곡 상세·작곡가)에서도 헤더 검색창으로 검색할 수 있다.
- [ ] 헤더 로고를 누르면 홈으로 간다. 헤더에 "작곡가" 메뉴가 있다.
- [ ] 푸터에 "악보 출처: IMSLP"와 저작권 안내 문구가 있다.
- [ ] 존재하지 않는 주소로 들어가면 "찾을 수 없는 페이지"가 나오고 홈 버튼과 검색창이 있다.
- [ ] 화면 폭이 모바일(360px)이어도 검색창·다운로드 버튼이 잘리지 않고 눌린다.

### 검색
- [ ] "월광"으로 검색하면 베토벤 피아노 소나타 14번이 결과에 나온다 (별칭 일치).
- [ ] "엘리제를 위하여", "엘리제", "Für Elise", "fur elise"로 검색하면 모두 같은 곡이 나온다.
- [ ] "쇼팽 녹턴"으로 검색하면 쇼팽의 녹턴만 나오고, 다른 작곡가의 녹턴은 나오지 않는다.
- [ ] "Chopin"과 "쇼팽"으로 검색한 결과에 같은 곡들이 나온다.
- [ ] "Op.27 No.2", "op 27 no 2", "op27no2"로 검색하면 모두 같은 곡이 나온다.
- [ ] "BWV 846"과 "BWV846"으로 검색한 결과가 같다. "K.545"와 "K545"도 같다.
- [ ] 대소문자를 바꿔 검색해도 결과가 같다.
- [ ] 검색어의 일부만 쳐도(예: "녹") 부분 일치로 결과가 나온다.
- [ ] 검색어가 작곡가 이름에 걸리면 결과 맨 위에 작곡가 카드가 보이고, 누르면 작곡가 상세로 간다.
- [ ] 결과 항목마다 한국어 제목, 원어 제목, 작곡가 한글(원어), 작품번호, 난이도, 추천 판본 쪽수(있을 때), 상태 뱃지(해당 시)가 보인다.
- [ ] 별칭으로 걸린 항목에는 어떤 별칭으로 걸렸는지 한 줄이 보인다.
- [ ] 결과 건수("N곡")가 표시된다.
- [ ] 난이도 필터를 "초급"만 켜면 초급 곡만 남고, "난이도 미정" 곡은 빠진다.
- [ ] 쪽수 필터 "10쪽 이하"를 켜면 추천 판본이 10쪽 이하인 곡만 남는다.
- [ ] "바로 받기 가능한 곡만" 필터를 켜면 준비 중·이용 제한·확인 중 곡이 빠진다.
- [ ] 결과가 20개를 넘으면 페이지 이동이 보이고 2페이지로 갈 수 있다.
- [ ] 결과 화면 주소를 복사해 새 탭에 붙여넣으면 같은 검색어·필터·페이지 결과가 보인다.
- [ ] 브라우저 뒤로 가기를 누르면 직전 화면으로 돌아간다.
- [ ] 없는 검색어로 검색하면 "찾지 못했어요" 안내와 예시 별칭, 인기곡 5개, 작곡가 목록 링크가 보인다.
- [ ] 필터로 0건이 되면 "필터 해제" 버튼이 보이고, 누르면 필터가 풀린다.
- [ ] 관리자가 숨긴 곡은 검색·인기곡·작곡가 상세 어디에도 나오지 않고, 주소로 들어가면 "찾을 수 없는 페이지"다.
- [ ] 빈 검색어로 Enter를 눌러도 화면이 이동하지 않고 오류 문구도 없다.

### 곡 상세
- [ ] 곡 상세에 한국어 제목, 원어 제목, 작곡가(누르면 작곡가 상세), 작품번호, 난이도, 별칭 목록이 보인다.
- [ ] 추천 판본 카드에 첫 페이지 미리보기, 판본 종류(전체 악보/파트보/편곡)·포함 범위, 쪽수, 파일 크기, 출판사·연도·편집자·스캔 제공자(있는 것), 한국 기준 저작권 뱃지, IMSLP 원문 표기, "출처: IMSLP" 링크가 보인다.
- [ ] "출처: IMSLP" 링크를 누르면 새 탭에서 그 곡의 IMSLP 작품 페이지가 열린다.
- [ ] 미리보기 이미지를 누르면 크게 보이고, 닫기 버튼이나 바깥을 누르면 닫힌다.
- [ ] 바로 받기 가능한 곡에서 "PDF 받기" 버튼을 **한 번** 누르면 확인 창·대기 화면 없이 PDF 파일이 내려온다.
- [ ] 내려온 파일이 정상적으로 열리는 PDF이고, 쪽수가 화면에 표시된 쪽수와 같다.
- [ ] 내려온 파일 이름에 작곡가 한글과 한국어 제목이 들어 있다.
- [ ] 다운로드 후 관리 홈의 다운로드 수가 1 증가하고, 인기곡 순위에 반영된다.
- [ ] 파일이 20MB 이상인 판본은 버튼 옆에 크기 경고 문구가 보이고, 그래도 클릭 1번으로 받아진다.
- [ ] 판본 종류가 IMSLP 원어(Complete Score 등)가 아니라 한국어(전체 악보 등)로 표시된다.
- [ ] 다른 판본이 있으면 "다른 판본 보기 (N개)"가 접힌 상태로 보이고, 펼치면 각 판본의 종류·쪽수·크기·출판사/편집자·뱃지와 "PDF 받기" 또는 "IMSLP에서 보기" 버튼이 보인다.
- [ ] 다른 판본이 없으면 "다른 판본 보기" 영역이 아예 보이지 않는다.
- [ ] 다른 판본의 "PDF 받기"도 클릭 1번으로 그 판본 파일이 내려온다.
- [ ] CC 라이선스 판본에는 라이선스 이름과 저작자 표기가 보인다.
- [ ] 악장 페이지 안내를 관리자가 적은 곡에는 그 문구가 보이고, 안 적은 곡에는 그 줄이 없다.
- [ ] 같은 작곡가의 다른 곡이 최대 5개 보이고, 누르면 그 곡 상세로 간다.
- [ ] 곡 상세 주소를 새 탭에 붙여넣으면 같은 곡이 열린다.

### 곡 상세 — 예외
- [ ] PDF가 없는 곡(준비 중)은 검색 결과에 "준비 중" 뱃지가 보이고, 상세에서 "악보를 준비하고 있어요" 문구와 "IMSLP에서 보기" 버튼이 보이며 다운로드 버튼이 없다.
- [ ] "이용 제한" 판정 곡은 검색 결과에 "한국에서 이용 제한" 뱃지가 보이고, 상세에 설명 문구와 "IMSLP에서 보기" 버튼이 보이며 다운로드 버튼이 없다.
- [ ] "확인 중" 판정 곡은 "저작권 확인 중" 뱃지가 보이고 다운로드 버튼이 없다.
- [ ] 추천 판본은 이용 제한이지만 다른 판본이 바로 받기 가능하면, 그 안내가 보이고 다른 판본에서 받을 수 있다.
- [ ] 미리보기 이미지가 없는 판본은 "미리보기 준비 중" 자리가 보이고 다운로드는 된다.
- [ ] 파일이 서버에서 사라진 판본의 "PDF 받기"를 누르면 "지금은 파일을 받을 수 없어요" 안내와 IMSLP 링크가 보이고, 다운로드 수는 늘지 않는다.
- [ ] 네트워크를 끊고 곡 상세를 열면 "연결을 확인해 주세요"와 "다시 시도" 버튼이 보이고, 연결 후 다시 시도하면 정상 표시된다.

### 작곡가
- [ ] 작곡가 목록이 한글 표기 가나다순이고, 공개 곡이 0개인 작곡가는 나오지 않는다.
- [ ] 작곡가 상세에 한글 표기, 원어 표기, 생몰년, IMSLP 링크(있으면), 곡 목록이 보인다.
- [ ] 작곡가 상세 곡 목록을 "작품번호 순"으로 바꿀 수 있고, 난이도·쪽수·바로 받기 필터가 검색 결과와 같게 동작한다.
- [ ] 곡이 20개를 넘는 작곡가는 페이지 이동이 된다.

### 관리자 — 진입
- [ ] ADMIN으로 로그인하면 헤더에 "관리" 메뉴가 생기고, 누르면 관리 홈이 열린다.
- [ ] USER로 로그인하면 "관리" 메뉴가 없고, 관리 주소로 직접 들어가면 "관리자만 들어갈 수 있어요" 안내가 보인다.
- [ ] 비로그인으로 관리 주소에 들어가면 로그인 화면으로 가고, 로그인 후 원래 가려던 관리 화면으로 돌아온다.
- [ ] 홈에서 로그인하면 로그인 후 홈으로 돌아온다.
- [ ] 관리 홈에 전체 곡 수 · 바로 받기 가능 · 준비 중 · 보완 필요 · 저작권 확인 중 판본 수 · 이번 달 다운로드 수가 보이고 실제 값과 맞는다.

### 관리자 — 작곡가·곡·별칭·난이도
- [ ] 작곡가를 한글 표기·원어 표기로 등록하면 목록에 나온다. 같은 원어 표기로 다시 등록하면 막힌다.
- [ ] 곡이 있는 작곡가는 삭제가 막히고 사유가 보인다.
- [ ] 곡을 작곡가·한국어 제목·원어 제목·작품번호로 등록하면 즉시 사용자 검색에 나온다 (판본이 없으므로 "준비 중").
- [ ] 곡에 별칭을 3개 넣으면 세 별칭 모두로 검색된다. 별칭 하나를 지우면 그 별칭으로는 더 이상 검색되지 않는다.
- [ ] 같은 곡에 같은 별칭을 두 번 넣으면 막힌다. 다른 곡에 이미 있는 별칭을 넣으면 경고가 보이지만 저장된다.
- [ ] 난이도를 "중급"으로 바꾸면 사용자 화면의 난이도와 필터에 즉시 반영된다.
- [ ] 곡을 "숨김"으로 바꾸면 사용자 화면에서 사라지고, 해제하면 다시 나온다.
- [ ] 한국어 제목·별칭·난이도·추천 판본 중 하나라도 비면 "보완 필요"로 표시되고, 편집 화면 상단에 빠진 항목이 나열된다. 모두 채우면 "보완 필요"가 사라진다.
- [ ] 곡 목록(관리)의 상태 필터 "보완 필요"로 그런 곡만 볼 수 있다.
- [ ] 악장 페이지 안내를 적으면 사용자 곡 상세에 그대로 보인다.
- [ ] 판본이 있는 곡을 삭제하려면 확인 창이 뜨고, 확인하면 판본·파일이 함께 지워지며 사용자 화면에서 사라진다.

### 관리자 — 판본
- [ ] 판본에 PDF를 올리면 쪽수·파일 크기·첫 페이지 미리보기가 자동으로 채워진다.
- [ ] PDF가 아닌 파일을 올리면 즉시 거부 문구가 보인다. 상한을 넘는 파일도 거부된다.
- [ ] 판본 종류를 전체 악보/파트보/편곡 중 고르고, 포함 범위를 전곡/특정 악장으로 고를 수 있다.
- [ ] 판본을 "추천으로 지정"하면 사용자 곡 상세의 추천 카드가 그 판본으로 바뀌고, 이전 추천은 "다른 판본"으로 내려간다.
- [ ] 파일 없는 판본은 추천 지정이 막힌다.
- [ ] 한국 기준 판정을 "자유 이용 가능"으로 바꾸고 메모를 쓰면 사용자 화면에 다운로드 버튼이 열린다. 메모 없이 저장하면 막힌다.
- [ ] 판정을 "이용 제한"으로 바꾸면 사용자 화면의 다운로드 버튼이 사라지고 IMSLP 링크만 남는다.
- [ ] 새로 만든 판본의 판정 기본값은 "확인 중"이다.
- [ ] 저작권 판정 대기함에 "확인 중" 판본만 나오고, 판정하면 목록에서 빠진다. 여러 개 선택해 일괄 판정할 수 있다.
- [ ] CC 라이선스 정보를 넣으면 사용자 곡 상세에 표시된다.
- [ ] 수집으로 만든 곡의 판본 목록에 "추천 후보"가 표시되고, 한 번 눌러 추천으로 확정할 수 있다.

### 관리자 — 수집
- [ ] 수집 관리 화면에 IMSLP 작품 페이지 주소를 여러 줄 붙여넣고 "확인"을 누르면 줄마다 수집 예정 / 형식 오류 / 이미 있음 / 중복 제거가 표시되고, 요약(건수·예상 시간)이 보인다.
- [ ] "요청 사이에 2초 이상 쉬며 천천히" 안내 문구가 화면에 있다.
- [ ] "수집 시작"을 누르면 진행 화면으로 가고, 진행 막대·성공/실패 수·현재 처리 중 항목·남은 예상 시간이 보인다.
- [ ] 진행 화면이 10초 안에 자동으로 갱신된다. "새로고침" 버튼도 동작한다.
- [ ] 수집 진행 중 브라우저를 닫고 다시 들어와도 진행이 계속되어 있고 현황이 보인다.
- [ ] 수집 중에는 "수집 시작" 버튼이 비활성이고 안내 문구가 보인다.
- [ ] "중지"를 누르면 처리 중이던 항목까지 끝난 뒤 멈추고, 상태가 "중지됨", "이어서 시작" 버튼이 보인다. 이어서 시작하면 대기 항목부터 계속된다.
- [ ] 수집이 끝나면 요약(총·성공·실패·건너뜀·걸린 시간)과 항목별 결과가 보인다.
- [ ] 성공한 항목의 곡이 곡 관리에 "보완 필요" 상태로 생기고, 원어 제목·작곡가 원어·작품번호·판본 정보·IMSLP 링크가 채워져 있다.
- [ ] 성공한 곡의 판본 중 "전체 악보" 상위 2개에 파일이 있고, 미리보기·쪽수·크기가 채워져 있다. 나머지 판본은 정보만 있고 "파일 없음"이다.
- [ ] 정보만 있는 판본에서 "파일 받아오기"를 누르면 그 판본 파일이 채워진다.
- [ ] 수집 직후의 곡을 사용자 검색에서 원어 제목으로 찾으면 "준비 중" 또는 "저작권 확인 중" 뱃지로 보이고 다운로드 버튼이 없다.
- [ ] 관리자가 한국어 제목·별칭·난이도를 넣고 추천 후보를 확정하고 판정을 "자유 이용 가능"으로 바꾸면, 사용자 화면에서 한국어 별칭으로 검색되고 다운로드 버튼이 열린다.
- [ ] 없는 IMSLP 주소를 넣으면 그 항목만 "페이지가 없어요"로 실패하고 나머지는 계속 진행된다.
- [ ] 이미 등록된 곡의 주소를 다시 넣으면 "이미 있음 — 건너뜀"이 되고, "정보만 다시 가져오기"를 켜도 파일을 다시 받지 않는다.
- [ ] "실패한 것만 다시 시도"를 누르면 실패 항목만으로 새 작업이 시작된다.
- [ ] 수집 중 서비스를 재시작하면 작업이 "중지됨"으로 남고 "이어서 시작"으로 재개되며, 이미 받은 파일은 다시 받지 않는다.
- [ ] 피아노 독주가 아닌 작품 주소를 넣으면 등록은 되되 숨김 상태이고 사유가 표시된다.
- [ ] 관리 화면 어디에서나 수집 진행 중이면 상단 띠가 보이고, 누르면 진행 화면으로 간다.

### 범위 밖 확인
- [ ] 일반 사용자 화면 어디에도 로그인해야만 되는 기능(즐겨찾기 등)이 없다.
- [ ] 다운로드 시 IMSLP 면책 페이지·대기 페이지·광고가 끼어들지 않는다.
- [ ] 화면 어디에도 피아노 독주 이외 편성을 고르는 메뉴가 없다.

## 7. 기존 화면·흐름과의 정합성

- **홈**: 기존 보일러플레이트 홈(HomePage)은 내용을 전면 교체한다. 주소(`/`)는 그대로.
- **로그인**: 기존 로그인 화면·회원가입 화면은 그대로 두되, 1차에서 일반 사용자에게 로그인을 권하는 문구는 어디에도 두지 않는다. 로그인 후 "원래 보던 화면으로 복귀"가 안 되면 홈으로 보낸다 (현재 동작 확인 필요 — qa).
- **헤더**: 로고 문구("Boilerplate")를 서비스 이름으로, 메뉴를 "작곡가"(+ 관리자에게만 "관리")로 바꾼다. 커뮤니티·채팅 메뉴는 §8-2 결정에 따른다.
- **마이페이지**: 1차에는 관리자만 로그인하므로 그대로 둔다. 헤더의 "마이페이지" 링크는 로그인 사용자에게만 보이는 현재 동작 유지.
- **페이지 이동 부품**: 기존 목록 페이지 이동 방식(20개씩)을 검색 결과·작곡가 상세에서도 같은 모양으로 쓴다.
- **파일**: 기존 파일 업로드 흐름이 있으니 관리자 PDF 업로드는 그 사용감(파일 선택 → 올리는 중 표시 → 완료)을 따른다.

### 9-1. 수집 방식 결정 (2026-09-06, `docs/설계/00_IMSLP_수집_조사.md` 반영)

조사 결과 IMSLP 는 파일 다운로드에 **봇 게이트(`friendlyredirect`) → 면책 동의 → 15초 대기** 3중 장치를 두고 있고, 메타데이터 경로(작품 페이지·`api.php`·공개 API)는 허용한다. 선임개발자 권고는 "메타데이터 자동 + PDF 는 관리자가 곡별 버튼으로 1회 대리 수신(B안)"이다. 사용자는 "파일도 크롤링으로 모으자"고 했다. 절충으로 다음을 **가정**하고 진행한다(사용자가 B안으로 바꾸면 수집 잡의 "파일 받기" 단계만 끄면 되도록 설계한다):

| 항목 | 결정 |
|---|---|
| 메타데이터 | 수집 잡이 자동 수집 (작품 페이지 HTML 1회 + 위키텍스트 1회, 2초 간격) |
| PDF | 수집 잡이 **곡당 "전체 악보" 상위 2개만** 자동 수신하되, **IMSLP 의 15초 대기를 우회하지 않고 그대로 기다린다**(파일당 최소 15초 + 요청 간 2초). 동시 1커넥션, 파일당 평생 1회, 식별 가능한 User-Agent(연락처 포함). 저작권 표기가 PD·CC0·CC-BY·CC-BY-SA 가 아닌 파일은 받지 않는다(정보만) |
| 예상 시간 | 곡당 약 1~2분 → 50곡 약 1시간. 기획서 F7 의 "천천히 가져옵니다" 안내 유지 |
| 개별 재수신 | 곡 편집의 "파일 받아오기" 버튼은 같은 규칙으로 1건씩 |
| 전환 스위치 | 관리자 수집 설정에 "파일도 함께 받기" 켜기/끄기(기본 켬). 끄면 B안과 동일 |
| IMSLP 연락 | 첫 배치 50곡 이후·확대 전에 사용자가 연락 여부 결정(8-10) |

> 보충(2026-09-06, 설계 반영): "전체 악보 상위 2개"는 **재배포 허용 표기(PD·CC0·CC-BY·CC-BY-SA)인 판본 중** 상위 2개다. NC/ND 판본이 상위여도 건너뛴다. 인기곡 정렬은 누적 다운로드 수 → 최근 등록 순으로 구현된다(기록 없는 곡끼리는 최근 등록순).
