> 경로: **`/piano/composers`** (목록), **`/piano/composers/:id?sort=&level=&pages=&downloadable=&page=`** (상세) — 확정 2026-09-10(00 §8). 옛 주소 `/composers`, `/composers/:id?…` 는 쿼리를 보존한 채 `/piano/…` 로 **replace 리다이렉트**(기획 04 §3-5). 작곡가는 구분에 속하지 않으므로 곡 상세 같은 자기 교정은 없다 — 곡 목록·곡 수만 현재 구분 기준(API 명세서 §0-7)
>
> **2026-09-10 개정 (기획 04 §5)**
> - 두 화면 모두 헤더 아래에 **악기 구분 바**가 붙고 현재 구분이 선택돼 보인다(00 §3-15 / 08 §1). 구분 바는 sticky 가 아니므로 **가나다 구분 헤더의 `top: var(--header-height)` 는 그대로 유효**하다.
> - 목록의 부제 `공개된 곡이 있는 작곡가 42명` 의 뜻이 **"현재 구분에서 공개 곡이 1개 이상"** 으로 좁아진다. **문구는 바꾸지 않는다** — 화면 전체가 이미 그 구분 안이고(탭·주소), "피아노에서 공개된 곡이 있는 작곡가"라고 쓰면 모든 화면에 구분 이름을 되풀이하게 된다.
> - 상세의 곡 목록·곡 수·정렬·필터도 **현재 구분 기준**. 화면 동작·문구는 그대로다.
> - 브라우저 탭 제목: `작곡가 — 쉬운악보 피아노` / `쇼팽 — 쉬운악보 피아노` (00 §4-1).

# 화면 A: 작곡가 목록

## 레이아웃

**모바일**
```
┌────────────────────────────────────┐
│ 헤더 (🔍 토글 있음)                  │
├────────────────────────────────────┤
│   피아노   │  바이올린  │ 오케스트라 │  구분 바 48px (sticky 아님)
│  ▔▔▔▔▔▔   │  준비 중   │  준비 중   │
├────────────────────────────────────┤
│ 👥 작곡가                           │  page-header (기존 .page-header)
│ 공개된 곡이 있는 작곡가 42명          │  --font-size-sm muted
│                                    │
│ ㄱ                                 │  가나다 구분 헤더 (sticky)
│ ┌────────────────────────────────┐ │
│ │ 그리그                    12곡 ›│ │
│ │ Grieg, Edvard · 1843–1907      │ │
│ ├────────────────────────────────┤ │
│ ㄷ                                 │
│ │ 드뷔시                     9곡 ›│ │
│ │ Debussy, Claude · 1862–1918    │ │
│ ├────────────────────────────────┤ │
│ │ …                              │ │
│ └────────────────────────────────┘ │
├────────────────────────────────────┤
│ 푸터                                │
└────────────────────────────────────┘
```

**데스크톱**: 같은 목록을 2열 그리드(gap `--space-4`)로. 가나다 구분 헤더는 열 전체 폭(`grid-column: 1 / -1`).

## 구성 요소

| 요소 | 문구 / 동작 | 토큰 / 재사용 |
|---|---|---|
| 페이지 제목 | 아이콘 `people` + `작곡가` | 기존 `.page-header` |
| 부제 | `공개된 곡이 있는 작곡가 42명` | `--font-size-sm` `--color-text-muted` |
| 가나다 구분 헤더 | 한글 표기 첫 글자의 초성(ㄱ, ㄴ, …). 한글 표기가 없는 작곡가(관리자 미입력)는 원어 표기 첫 알파벳(A, B, …)으로 **맨 뒤**에 묶음. 서버 정렬(한글 가나다순)을 그대로 쓰고 초성 계산은 화면에서 | `--font-size-sm` `--font-weight-medium` `--color-primary`, 배경 `--color-bg`, sticky `top: var(--header-height)` |
| 작곡가 행 | 1줄: 한글 표기(`--font-size-base` medium) + 오른쪽 `12곡 ›` / 2줄: `원어 표기 · 생몰년`(`--font-size-sm` muted). 생몰년은 `1843–1907`(en dash). 몰년 없으면 `1843–`, 둘 다 없으면 생략. 행 전체 → `/piano/composers/:id`(현재 구분 — 00 §8 링크 규칙) | 기존 `.post-list`/`.post-item` 패턴, 높이 ≥ `--touch-target` |
| 페이지 이동 | **없음** — 1차 규모(작곡가 수십 명)에서는 전체 목록 한 번에. 200명 넘으면 재검토 | — |

## 상태별 UI

| 상태 | 표시 |
|---|---|
| 로딩 | 제목 즉시. 목록 스켈레톤 8줄(2줄짜리) |
| 불러오기 실패 | `연결을 확인해 주세요` + `다시 시도` (00 §3-9) |
| 0명 | `.empty-state` 아이콘 `people_outline`: 제목 `아직 등록된 작곡가가 없어요` / 보조 `곡이 등록되면 작곡가도 함께 보여요` |
| 한글 표기 없는 작곡가 | 1줄에 원어 표기를 medium 으로, 2줄에 생몰년만 |

## 플랫폼 차이

- 앱 미도입. 모바일 1열, 데스크톱 2열.

# 화면 B: 작곡가 상세

## 레이아웃

**모바일**
```
┌────────────────────────────────────┐
│ 헤더 (🔍 토글 있음)                  │
├────────────────────────────────────┤
│ 쇼팽                               │  h1 --font-size-2xl
│ Chopin, Frédéric                   │  원어, muted
│ 1810–1849 · 폴란드                  │  생몰년 · 국적(있으면)
│ 쇼팡이라고도 씁니다                  │  검색용 별칭(있으면)
│ IMSLP 작곡가 페이지 보기 ↗           │  링크(있으면)
│                                    │
│ 곡 24개                    [정렬 ▾] │  건수 · 정렬 select
│ ┌ 난이도 […] 쪽수 […] ☐ 바로 받기 가능한 곡만 ─▶ │  FilterBar
│ ┌────────────────────────────────┐ │
│ │[A4] 녹턴 2번             [준비 중]│ │  WorkCard (작곡가 줄 생략)
│ │     Nocturne in E-flat major    │ │
│ │     Op.9 No.2                   │ │
│ │     [중급] 5쪽                  │ │
│ ├────────────────────────────────┤ │
│ │ …  (20개)                       │ │
│ └────────────────────────────────┘ │
│        [‹] [1] [2] [›]             │
├────────────────────────────────────┤
│ 푸터                                │
└────────────────────────────────────┘
```

**데스크톱**: 본문 1200px. 작곡가 정보는 상단 흰 카드(`--radius-md` `--shadow-sm` padding `--space-6`) 안에 2열(왼쪽 이름·원어·생몰년, 오른쪽 별칭·IMSLP 링크). 목록은 검색 결과와 동일.

## 구성 요소

| 요소 | 문구 / 동작 | 토큰 / 재사용 |
|---|---|---|
| 한글 표기 (h1) | 없으면 원어 표기를 h1 로 | `--font-size-2xl`/`3xl` medium |
| 원어 표기 | | `--font-size-base` muted |
| 생몰년 · 국적 | `1810–1849 · 폴란드`. 있는 것만, 없으면 줄 생략 | `--font-size-md` `--color-text-secondary` |
| 검색용 별칭 | `쇼팡이라고도 씁니다` / 여러 개면 `쇼팡, 쇼팡 프레데리크라고도 씁니다`. 없으면 생략 | `--font-size-md` muted |
| IMSLP 링크 | `IMSLP 작곡가 페이지 보기 ↗` (새 탭). 없으면 생략 | `--color-link` `--font-size-sm`, `open_in_new` |
| 건수 | `곡 24개` / 필터 시 `곡 24개 중 8개` | `--font-size-base` medium |
| 정렬 | 기존 `.filter-select`: 옵션 `다운로드 많은 순`(기본, `sort=downloads`) / `작품번호 순`(`sort=opus`). 바꾸면 `page=0`, URL 갱신 | 기존 |
| 필터 바 | FilterBar — 검색 결과와 **동일 컴포넌트·동일 쿼리 이름** | 공통 |
| 곡 목록 | WorkCard ×20, **작곡가 줄 생략**(작품번호만). 별칭 일치 줄 없음 | 공통 |
| 페이지 이동 | 기존 `Pagination`, `page` 쿼리 | 기존 |

## 상태별 UI

| 상태 | 표시 |
|---|---|
| 로딩 | 작곡가 정보 스켈레톤(제목 + 2줄) + 목록 스켈레톤 5개. 정보와 목록은 독립 요청이어도 되고 하나여도 됨(senior-dev) |
| 불러오기 실패 | 본문 가운데 `연결을 확인해 주세요` + `다시 시도` |
| 없는 작곡가 (404) | `찾을 수 없는 페이지` 화면 (00 §2-4) |
| 공개 곡 0개 (필터 없음) | 목록 자리 `.empty-state` 아이콘 `library_music`: `아직 공개된 곡이 없어요`. (목록에서는 안 보이지만 주소로 들어온 경우) |
| 필터 0건 | `이 조건에 맞는 곡이 없어요` + `필터 해제` (검색 결과와 동일) |
| 페이지 범위 밖 | `이 페이지에는 곡이 없어요` + `첫 페이지로` |
| 준비 중 / 이용 제한 / 확인 중 곡 | 카드 상태 뱃지 |
| 한글 표기 없음 | h1 원어, 원어 줄 생략. 곡 카드는 영향 없음 |

## 플랫폼 차이

- 앱 미도입.
- 모바일: 정렬 select 는 건수 줄 오른쪽에 작게(높이 36px), 필터는 가로 스크롤. 데스크톱: 필터 바 한 줄, 정렬은 그 오른쪽 끝.
