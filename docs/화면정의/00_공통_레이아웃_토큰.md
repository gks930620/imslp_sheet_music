```
│ [♪ 쉬운악보]        [🔍]  [☰]     │   🔍 = 헤더 검색 토글(홈 이외 화면), ☰ = 메뉴 토글
```

## 3. 공통 컴포넌트

> 클래스 이름은 제안이다. frontend-dev 가 바꿔도 되지만 **한 컴포넌트 = 한 파일**로 만들어 화면마다 재사용한다. 색·크기는 전부 토큰.

### 3-1. 검색창 `SearchBar`

```
large  (홈, 검색 결과 상단, 찾을 수 없음)
┌──────────────────────────────────────────────────────┬────────┐
│ 🔍  곡 이름, 작곡가, 작품번호로 찾기 — 예: 월광, 쇼팽 녹턴, K.545 │  검색  │
└──────────────────────────────────────────────────────┴────────┘
compact (헤더)
┌──────────────────────────────┐
│ 🔍  곡 이름, 작곡가, 작품번호   │      (버튼 없음, Enter 만)
└──────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 자리 문구 large | `곡 이름, 작곡가, 작품번호로 찾기 — 예: 월광, 쇼팽 녹턴, K.545` (모바일 360px 에서 잘리면 `곡 이름, 작곡가, 작품번호 — 예: 월광, K.545`) |
| 자리 문구 compact | `곡 이름, 작곡가, 작품번호` |
| 높이 | large 52px(모바일 48px) / compact 40px |
| 글자 | large `--font-size-base` / compact `--font-size-md` |
| 경계 | `1px solid --color-border`, 포커스 시 `--color-primary` 2px, 반경 `--radius-md` |
| 아이콘 | `search` (`--color-text-muted`), 입력 중엔 오른쪽에 `close` 지우기 버튼 |
| 버튼 | large 만 "검색" (`.btn.btn-primary`, 높이 검색창과 동일). 모바일에선 버튼을 입력칸 안 오른쪽에 아이콘 버튼(`search`)으로 접어 한 줄 유지 |
| 동작 | Enter 또는 버튼 → 검색 결과. **공백만이면 이동하지 않고** 입력칸이 좌우 4px 흔들림(`--duration-fast` × 2) + 경계선이 잠깐 `--color-primary`. 오류 문구 없음 |
| 기존 | `.search-input-wrapper` 의 구조(아이콘 absolute + input padding-left 40px)를 그대로 따라 만든다 |

### 3-2. 곡 카드 `WorkCard` (목록 항목)

검색 결과·작곡가 상세·홈 인기곡·같은 작곡가의 다른 곡에 공통. 전체가 링크(곡 상세).

```
┌──────────────────────────────────────────────────────────────┐
│ ┌────┐  월광 소나타                          [준비 중]         │  ← 한국어 제목 굵게 / 상태 뱃지(해당 시)
│ │ A4 │  Piano Sonata No.14                                     │  ← 원어 제목
│ │thumb│ 베토벤 (Beethoven, Ludwig van) · Op.27 No.2            │  ← 작곡가(원어) · 작품번호
│ └────┘  [중급]  12쪽                                          │  ← 난이도 칩 · 추천 판본 쪽수
│         '월광'으로 찾음                                       │  ← 별칭 일치 줄 (검색 결과에서만)
└──────────────────────────────────────────────────────────────┘
```

| 항목 | 규칙 |
|---|---|
| 축소 이미지 | 추천 판본 첫 페이지. 폭 `--thumb-width-list`(56px, 데스크톱 72px), 비율 `--thumb-aspect`. **없으면 자리 자체를 두되** `--color-surface-placeholder` 배경에 `music_note` 아이콘(`--color-text-disabled`) — 목록에서는 "미리보기 준비 중" 글자를 넣지 않는다(좁음) |
| 제목 | `--font-size-base` `--font-weight-medium` `--color-text`. 한국어 제목이 없으면(관리자 미입력) 원어 제목을 이 자리에 쓰고 원어 줄은 생략 |
| 원어 제목 | `--font-size-sm` `--color-text-muted` |
| 작곡가 | `--font-size-sm` `--color-text-secondary`. 작곡가 상세 화면에서는 이 줄에서 작곡가를 빼고 작품번호만 |
| 작품번호 | `--font-family-mono` 는 쓰지 않는다(카드에선 본문체). 여러 개면 " · " 로 이어 붙임 |
| 난이도 | 난이도 칩(§3-3). 미정이면 "난이도 미정" 칩 |
| 쪽수 | "12쪽". 추천 판본 없으면 표시 안 함 |
| 상태 뱃지 | 준비 중 / 한국에서 이용 제한 / 저작권 확인 중 중 하나. 바로 받기 가능이면 **없음**. 제목 줄 오른쪽 (모바일에선 제목 아래 줄로 내려감) |
| 별칭 일치 줄 | `'월광'으로 찾음` — 검색어가 **별칭**에 걸렸을 때만. `--font-size-xs` `--color-primary`. 대표 제목·작곡가·작품번호로 걸린 건 표시 안 함 |
| 컨테이너 | 기존 `.post-list` / `.post-item` 패턴(흰 카드 안에 행, 경계선 `--color-border`, hover `--color-surface-muted`) 재사용. 한 항목 padding `--space-4`(모바일) / `--space-5` |
| 터치 | 항목 전체 높이 ≥ `--touch-target` |

**compact 변형** (홈 인기곡·같은 작곡가의 다른 곡): 축소 이미지 없이 `순위 숫자 · 한국어 제목 · 작곡가 · 난이도 칩` 한 줄. 상태 뱃지는 표시.

### 3-3. 난이도 칩 `LevelChip`

| 값 | 문구 | 토큰 | 한 줄 기준 (툴팁 `title` + 필터 도움말) |
|---|---|---|---|
| BEGINNER | 입문 | `--level-beginner-*` | 바이엘 수준 |
| ELEMENTARY | 초급 | `--level-elementary-*` | 체르니 30 수준 |
| INTERMEDIATE | 중급 | `--level-intermediate-*` | 체르니 40·소나티네 수준 |
| ADVANCED | 고급 | `--level-advanced-*` | 체르니 50 이상·연주회 레퍼토리 |
| (없음) | 난이도 미정 | `--level-unknown-*` | — |

- 모양: pill(`--radius-pill`), 높이 22px, padding `0 --space-2`, `--font-size-xs` `--font-weight-medium`. 배경 `*-bg`, 글자 `*-text`, 경계 없음.
- 저작권 뱃지(§3-4)와 **모양을 다르게** 한다: 칩은 둥근 pill·아이콘 없음, 뱃지는 각진 사각·아이콘 있음.
- 필터에서 쓰는 토글 칩도 같은 모양. 선택 시 배경 `--color-primary`, 글자 `--color-on-primary`.

### 3-4. 저작권 뱃지 `CopyrightBadge` 3종 + 준비 상태 뱃지

| 값 | 문구 | 아이콘 | 토큰 | 사용자가 할 수 있는 것 |
|---|---|---|---|---|
| FREE | 한국에서 자유 이용 가능 | `check_circle` | `--badge-free-*` | PDF 받기 |
| RESTRICTED | 한국에서 이용 제한 | `block` | `--badge-restricted-*` | IMSLP 링크만 |
| UNKNOWN | 저작권 확인 중 | `help` | `--badge-unknown-*` | IMSLP 링크만 |
| (곡 상태) PREPARING | 준비 중 | `hourglass_empty` | `--badge-preparing-*` | IMSLP 링크만 |

- 모양: 사각(`--radius-sm`), 높이 24px, padding `0 --space-2`, `--font-size-xs` `--font-weight-medium`, `1px solid *-border`, 아이콘 `--icon-size-sm`.
- 목록(곡 카드)에서는 FREE 뱃지를 **표시하지 않는다** (기획: 바로 받기 가능은 뱃지 없음). 곡 상세 판본 카드·판본 행에서는 FREE 도 표시.
- **문구 출처**: 기획서 01 §0-3 및 qa 인수조건("한국에서 이용 제한"). 지침 02 는 "한국에서는 보호 중"이라 적혀 있어 **불일치** — product-planner 가 02 를 01 에 맞춰 고쳐 달라고 되돌린다. 화면은 01 을 따른다.

### 3-5. 판본 카드 `EditionCard` (추천 판본, 곡 상세의 주인공)

상세 정의는 `03_곡상세.md` §3-2. 여기서는 형태만.

```
데스크톱                                              모바일
┌─────────────────────────────────────────────┐      ┌──────────────────────┐
│ 추천 판본                                    │      │ 추천 판본             │
```

## 5. 접근성 최소 기준

- 모든 아이콘 전용 버튼에 `aria-label` (검색, 닫기, 메뉴, 지우기, 페이지 이동).
- 뱃지·칩은 색만으로 구분하지 않는다 — 문구·아이콘이 항상 같이 있다.
- 포커스 링: 키보드 포커스 시 `outline: 2px solid --color-primary; outline-offset: 2px`. 마우스 클릭 시엔 숨김(`:focus-visible`).
- 본문 대비: `--color-text-muted`(#757575) 이하로 더 흐린 글자를 본문에 쓰지 않는다.
- 라이트박스·모달은 열릴 때 포커스를 안으로, 닫히면 원래 요소로.

## 7. 토큰 → 기존 `styles.css` 마이그레이션 지시 (frontend-dev)

> `styles.css` 는 designer 가 고치지 않는다. 아래 표대로 **값을 변수 참조로 바꾸기만** 하면 화면은 그대로다. 새 화면 CSS 는 처음부터 변수로 쓴다.

1. `frontend/src/main.jsx` 에서 `import "./styles/tokens.css";` 를 `import "./styles.css";` **앞에** 추가.
2. `body { font-family: "Roboto", sans-serif; color: #333 }` → `var(--font-family)`, `var(--color-text-body)`. `.comment-textarea`, `.form-input, .form-textarea` 의 `font-family` 도 동일.
3. 치환표 (전역 찾아 바꾸기 가능한 순수 값):

| 기존 값 | 토큰 |
|---|---|
| `#6200ea` | `var(--color-primary)` |
| `#5000ca`, `#5000d7` | `var(--color-primary-hover)` (두 값을 하나로 통일) |
| `#3700b3` | `var(--color-primary-dark)` |
| `#ede7f6` | `var(--color-primary-light)` |
| `rgba(98, 0, 234, 0.3)` / `0.4` / `0.2`(spinner) / `0.15`(room hover) | `var(--color-primary-shadow)` / `--color-primary-shadow-hover` / spinner·room 은 그대로 두거나 `--shadow-primary` |

## 8. 라우트 (확정 — API 명세서 `docs/설계/02_API_명세서.md` §0-5 와 일치, 2026-09-06 대조)

화면 정의서에서 이 경로를 참조한다. 서버는 catch-all 로 `index.html` 을 돌려주므로 새 화면 추가 시 백엔드 수정 불필요. 화면 셸 permitAll 목록(`/search`, `/works/**`, `/composers/**`, `/admin`, `/admin/**`)은 아래 표와 같다. 이름이 바뀌면 senior-dev 가 명세서와 이 표를 함께 고친다.

| 화면 | 경로 |
|---|---|
| 홈 | `/` |
| 검색 결과 | `/search?q=&level=&pages=&downloadable=&page=` |
| 곡 상세 | `/works/:id` |
| 작곡가 목록 / 상세 | `/composers` / `/composers/:id?sort=&level=&pages=&downloadable=&page=` |
| 로그인 | `/login?redirect=` (기존, 복귀 파라미터만 추가) |
| 관리 홈 | `/admin` |
| 작곡가 목록(관리) / 등록 / 수정 | `/admin/composers` / `/admin/composers/new` / `/admin/composers/:id` |
| 곡 목록(관리) / 등록 / 수정(+판본) | `/admin/works` / `/admin/works/new` / `/admin/works/:id` |
| 저작권 판정 대기함 | `/admin/copyright` |
| 수집 관리 / 수집 진행·결과 | `/admin/crawl` / `/admin/crawl/:jobId` |
| 권한 없음 | (관리 경로에서 USER 일 때 같은 주소에 렌더) |
| 찾을 수 없음 | `*` |
| 범위 밖(유지) | `/signup`, `/mypage`, `/community/**`, `/rooms/**` — 헤더 메뉴만 제거, 주소는 열림(01 §9 8-2) |

쿼리 값(확정, API 쿼리 이름과 동일 — `02_API_명세서.md` §3-1·§3-8·§4-6):
- `level` — 사용자 화면은 쉼표 구분 복수(`level=ELEMENTARY,INTERMEDIATE`), 관리 곡 목록은 단일(`BEGINNER|ELEMENTARY|INTERMEDIATE|ADVANCED|NONE`, NONE=미정)
- `pages` — `LE10 | 11_20 | GE21` 단일
- `downloadable` — `true` 일 때만 의미 있음
- `sort`(작곡가 상세) — `downloads`(기본) | `opus`
- `page` — 0-base
- `/admin/works?q=&status=&composerId=&level=&page=` — `status=READY|PREPARING|RESTRICTED|UNKNOWN|NEEDS_WORK|HIDDEN`
- `/admin/copyright?q=&composerId=&page=`
