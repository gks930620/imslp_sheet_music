# 공통: 관리 화면 틀 · 진입

```
┌─────────────────────────────────────────────────────────────┐
│ 헤더 ("관리" 메뉴 active)                                     │
├─────────────────────────────────────────────────────────────┤
│ ⓘ 수집 진행 중 12/50 — 보기                                   │  AdminBanner: 진행 중 작업이 있을 때만, /admin* 전체
├─────────────────────────────────────────────────────────────┤
│ 관리 › 곡 관리 › 월광 소나타                                    │  브레드크럼 (--font-size-sm muted, 마지막은 text)
│                                                             │
│ (화면 본문)                                                  │
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| 브레드크럼 | `관리 › {목록} › {항목}`. 각 단계 링크. 관리 홈에서는 표시 안 함 |
| AdminBanner | 00 §3-14. 문구 `수집 진행 중 12/50 — 보기`. "보기" → `/admin/crawl/:jobId`. 일시 정지 상태면 `수집 일시 정지 — IMSLP가 응답하지 않아요 — 보기` (warning 톤), 중지됨이면 띠 없음 |
| 권한 없음 (USER) | 관리 경로 그 자리에 AccessDenied 렌더: 아이콘 `lock` 64px / 제목 `관리자만 들어갈 수 있어요` / `.btn.btn-primary` `홈으로`. 헤더에 "관리" 메뉴 없음 |
| 비로그인 | `/login?redirect={원래 경로}` 로 이동. 로그인 후 원래 관리 화면으로 복귀 |
| 세션 만료(저장 시) | 00 §4: InlineAlert danger `로그인이 풀렸어요. 다시 로그인해 주세요` + `작성 중이던 내용은 저장되지 않았어요` → 2초 후 로그인 화면(redirect 포함) |
| 인증 확인 중 | 본문 가운데 기존 `.spinner` (헤더는 즉시) |

## 구성 요소

| 항목 | 입력 / 규칙 / 문구 |
|---|---|
| 제목 | 등록 `새 작곡가` / 수정 `작곡가 수정` |
| 한글 표기 * | `.form-input`. 비면 `한글 표기를 입력해 주세요` |
| 원어 표기 * | `.form-input`. 도움말 `성, 이름 순으로 적어 주세요 (IMSLP 표기와 같게)`. 비면 `원어 표기를 입력해 주세요`. 중복(409 `DUPLICATE_RESOURCE`) → 필드 아래 `이미 등록된 작곡가예요 — 보기`. 에러 응답에 기존 id 가 없으므로 "보기"는 화면이 `GET /api/admin/composers?q={입력한 원어 표기}` 를 호출해 **첫 항목의 id** 로 `/admin/composers/{id}` 에 이동한다(새 탭 아님; 이동 전 변경 사항 있으면 이탈 확인 ConfirmDialog). 조회 중엔 "보기"에 작은 스피너, 조회 결과가 0건이면 "보기" 대신 `작곡가 목록에서 찾기` → `/admin/composers?q=…` |
| 검색용 별칭 | TagInput. 자리 문구 `별칭 입력 후 Enter`. 같은 별칭 중복 추가 시 무시 + 칩 흔들림 |
| 생년 / 몰년 | 숫자 4자리 입력 2개, 사이 `–`. 도움말 `저작권 판정 근거로 쓰이니 입력을 권장해요`. 몰년 < 생년이면 `몰년이 생년보다 앞서요` |
| 국적 | `.form-input` 선택 |
| IMSLP 작곡가 페이지 | `.form-input` 선택. `https://imslp.org/` 로 시작하지 않으면 `IMSLP 주소가 아니에요` |
| 저장 | `.btn.btn-primary` `저장`. 저장 중 `저장 중…` disabled. 성공 → **목록으로 이동** + Toast `저장했어요` |
| 취소 | `.btn.btn-secondary` → 목록. 변경 사항 있으면 ConfirmDialog `작성 중인 내용이 사라져요` [계속 작성] [나가기] |
| 삭제 | `.btn.btn-danger` (수정 화면만). 곡 0개: ConfirmDialog `이 작곡가를 삭제할까요?` [취소] [삭제]. 곡 있음: 버튼은 활성이되 누르면 InlineAlert danger `곡 12개가 있어 삭제할 수 없어요. 곡을 먼저 옮기거나 지우세요` (확인 창 없이 즉시 안내) |

## 구성 요소

| 항목 | 입력 / 규칙 / 문구 |
|---|---|
| 제목 | 등록 `새 곡` / 수정 `곡 수정` |

| 보완 필요 알림 | InlineAlert warning: `빠진 것: 한국어 제목, 별칭, 난이도, 추천 판본` — 빠진 항목만 나열. 오른쪽 끝 `보완 필요` 뱃지. 저장 후 다시 계산해 갱신/사라짐 |
| 작곡가 한글 없음 알림 | InlineAlert warning: `작곡가 한글 표기가 없어요 → 작곡가 편집`(링크 → `/admin/composers/:id`, 새 탭 아님. 돌아오면 현재 입력이 남도록 저장을 먼저 권함: `저장 후 이동`) |
| 작곡가 * | 검색 가능한 select(입력하면 목록이 좁혀짐, 기존 `.filter-select` 기반 + 입력). 표시 `한글 (원어)`. 없으면 옵션 맨 아래 `+ 새 작곡가 등록`(→ `/admin/composers/new`, 새 탭). 비면 `작곡가를 골라 주세요` |
