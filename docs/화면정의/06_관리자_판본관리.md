## 구성 요소

| 항목 | 입력 / 규칙 / 문구 |
|---|---|
| 제목 | `판본 추가` / `판본 수정` |
| PDF 파일 | 기존 `.file-upload-area` 재사용. 문구 `PDF 파일을 끌어다 놓거나 눌러서 선택` / `PDF만, 100MB 이하`. `accept="application/pdf"`. 선택 즉시 업로드 시작 → 진행 막대 + `올리는 중… 34%` → 완료 시 **쪽수·크기·미리보기 자동 채움** + 미리보기 썸네일(80px). 파일 있으면 `교체`(`.btn.btn-outline` 작은 크기) → 같은 흐름, 완료 시 쪽수·크기·미리보기 다시 채움 |
| 판본 종류 * | 라디오 `전체 악보` / `파트보` / `편곡`. 비면 `판본 종류를 골라 주세요` |
| 포함 범위 * | 라디오 `전곡` / `특정 악장` + 악장 번호 숫자 입력(1 이상). 특정 악장 선택 시 번호 필수 `악장 번호를 입력해 주세요` |
| 쪽수 | 숫자. 도움말 `PDF에서 자동으로 채워요. 고칠 수 있어요`. 파일 없으면 직접 입력 가능(수집 정보) |
| 출판사 / 출판 연도 / 플레이트 번호 / 편집자 / 스캔 제공자 | `.form-input` 선택 |
| IMSLP 파일 페이지 | `.form-input`. 수집 시 자동. `https://imslp.org/` 검사 |
| IMSLP 저작권 표기 | `.form-input` 원문. 수집 시 자동 |

| 저장 | `.btn.btn-primary` `저장` → 모달 닫힘 + 목록 갱신 + Toast `저장했어요`. 판정을 FREE 로 바꿨고 이 판본이 추천이면 Toast `저장했어요 — 사용자 화면에서 다운로드가 열렸어요` |

## 구성 요소

| 요소 | 문구 / 동작 |
|---|---|
| 제목·건수 | `저작권 판정 대기함` / `확인 중인 판본 19개` |
| 검색·필터 | SearchBar compact `곡 이름, 작곡가` / 작곡가 select |
| 표 열 | 체크 / 곡(한국어 없으면 원어, 링크 → `/admin/works/:id` 새 탭 `open_in_new`) / 작곡가 (몰년) — 몰년 없으면 `(몰년 없음)` `--color-warning` / 판본 `{종류}·{범위}` / 편집자(없으면 `–`) / IMSLP 표기 원문 + 파일 페이지 링크 ↗ / 판정 영역 |
| 행 판정 | 토글 버튼 2개 `자유 이용 가능`(선택 시 `--badge-free-*` 배경) / `이용 제한`(`--badge-restricted-*`) + 메모 입력(한 줄) + `저장`(`.btn.btn-primary` 작은 크기, 판정+메모 둘 다 있을 때만 활성). 저장 성공 → 행이 **사라지고** Toast `판정했어요`. 건수 -1 |
| 일괄 바 | 체크 1개 이상 시 표 위 sticky(`--z-banner`, 배경 `--color-primary-light`): `선택 {N}개` · 판정 라디오 · 메모 · `선택한 {N}개에 적용`. 적용 → ConfirmDialog `{N}개 판본을 '{판정}'으로 판정할까요?` 본문에 메모 미리보기 → 성공 시 행들 사라짐 + Toast `{N}개를 판정했어요`. 메모 없으면 버튼 disabled + `판정 근거를 적어 주세요` |
| 전체 선택 | 헤더 체크박스 = 현재 페이지 전체 |
| 정렬 | 작곡가 몰년 오래된 순(판정 쉬운 것부터, 서버). UI 없음 |
| 페이지 | 기존 Pagination, 20개 |

## 상태별 UI

| 상태 | 표시 |
|---|---|
| 로딩 | 표 스켈레톤 |
| 실패 | `연결을 확인해 주세요` + `다시 시도` |
