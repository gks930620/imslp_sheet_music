- 상단 소개 영역: 배경은 페이지 바탕 그대로(기존 보라 그라데이션 hero **사용 안 함** — 검색창이 주인공이어야 하므로 배경을 비운다). 상하 padding `--space-10`(모바일 `--space-6`).
- 인기곡 : 작곡가 = 데스크톱 `7fr : 5fr`, gap `--space-8`. 태블릿(600~1023)은 세로 쌓기, 작곡가 4열.

## 구성 요소

| 요소 | 문구 / 동작 | 토큰 / 재사용 |
|---|---|---|
| 서비스 이름 (h1) | `쉬운악보` | `--font-size-4xl`(모바일) / `--font-size-display`(데스크톱), `--font-weight-medium`, `--color-text`. 가운데 |
| 한 줄 설명 | `한국어로 검색하고 바로 받는 피아노 악보` | `--font-size-base`, `--color-text-muted`, 아래 `--space-6` |
| 검색창 | SearchBar **large** (00 §3-1). 자리 문구 `곡 이름, 작곡가, 작품번호로 찾기 — 예: 월광, 쇼팽 녹턴, K.545`. **화면이 열리면 자동 포커스**(`autoFocus`). Enter/버튼 → `/search?q=검색어` | 공통 |
| 예시 칩 | `예:` 라벨 + 칩 `월광` `쇼팽 녹턴` `K.545`. 누르면 그 검색어로 `/search?q=` 이동 | 칩 모양 00 §3-3, 배경 `--color-surface-muted`, 글자 `--color-text-secondary`, hover `--color-primary-light`. 라벨 `--font-size-sm` muted. 고정 3개(기획서 예시와 동일) |
| "인기곡" 제목 | `인기곡` | h2 `--font-size-xl` `--font-weight-medium`, 아래 `--space-3` |
| 인기곡 목록 | WorkCard **compact** ×10: `순위 · 한국어 제목 · 작곡가 한글 · 난이도 칩 · (상태 뱃지)`. 누르면 `/works/:id`. 정렬은 서버(누적 다운로드 순, 기록 없으면 최근 등록순) — 화면은 순서를 바꾸지 않는다 | 순위 숫자 `--font-size-lg` `--font-weight-medium` `--color-primary`, 폭 28px 고정. 컨테이너 기존 `.post-list` 카드 |
| "작곡가" 제목 + 링크 | `작곡가` / 오른쪽 `모든 작곡가 보기 ›` (`chevron_right`) → `/composers` | 링크 `.btn.btn-text` `--font-size-md` |
| 작곡가 카드 ×8 | 한글 표기(`--font-size-base` medium) + `N곡`(`--font-size-sm` muted). 누르면 `/composers/:id`. 서버가 곡 수 많은 순 8명 | 흰 카드 `--radius-md` `--shadow-sm` padding `--space-4`, hover `--shadow-md` + `translateY(-2px)`(기존 `.feature-card` hover 느낌). 그리드 모바일 2열, 태블릿 4열, 데스크톱 4열 |

## 상태별 UI

| 상태 | 표시 |
|---|---|
| **로딩** (인기곡·작곡가 동시 요청) | 검색창은 즉시 렌더·포커스. 인기곡 자리 스켈레톤 5줄(순위 원 + 제목 줄), 작곡가 자리 스켈레톤 카드 4개. 두 영역 독립 |
| **인기곡 불러오기 실패** | 인기곡 영역 안에만 `연결을 확인해 주세요` + `다시 시도`(00 §3-9, 아이콘 없이 작게: 제목 `--font-size-md`). 검색창·작곡가 영역은 영향 없음 |
| **작곡가 불러오기 실패** | 위와 같이 작곡가 영역 안에만 |
| **인기곡 0개** (곡이 아직 하나도 없음) | 인기곡 영역: 아이콘 `library_music` 48px + `아직 등록된 곡이 없어요` (`--font-size-md` muted). 영역 제목은 유지 |
| **작곡가 0명** | 작곡가 영역: `아직 등록된 작곡가가 없어요`. "모든 작곡가 보기" 링크는 그대로(목록 화면의 빈 상태로 이어짐) |
| **빈 검색어 Enter** | 이동 없음. 검색창 흔들림 + 경계 강조(00 §3-1). 오류 문구 없음 |
| **인기곡 중 준비 중/이용 제한 곡** | compact 카드에 상태 뱃지 표시(제목 오른쪽, 모바일은 아래 줄) |
| **로그인 상태** | 홈 내용은 동일. 헤더만 다름 |

## 플랫폼 차이

- 앱(Flutter) 미도입 — 웹 반응형만.
- 모바일: 검색 버튼은 입력칸 안 아이콘(`search`). 데스크톱: 입력칸 오른쪽 "검색" 버튼.
- 모바일에서 `autoFocus` 는 iOS Safari 가 키보드를 자동으로 띄우지 않을 수 있다 — 포커스는 걸되 키보드 강제 표시는 시도하지 않는다(qa: "커서가 검색창에 있다" 기준은 포커스 여부).
