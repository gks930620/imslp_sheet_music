### 3-4. 같은 작곡가의 다른 곡

- h2 `같은 작곡가의 다른 곡` (`--font-size-xl`), WorkCard **compact** 최대 5개(순위 숫자 없음, 작곡가 줄 생략). 누르면 그 곡 상세(스크롤 맨 위).
- 0개면 **영역 생략**.

### 3-5. 미리보기 크게 보기 `PreviewLightbox` (00 §3-10)

- 트리거: 추천 판본 미리보기, 다른 판본 행 썸네일.
- 캡션 `월광 소나타 — 전체 악보 · 전곡 (1쪽/12쪽)`.
- 닫기: `close` 버튼 / 바깥 클릭 / Esc. 닫히면 포커스가 눌렀던 이미지로 돌아간다.

## 상태별 UI

### 곡 준비 상태에 따른 추천 판본 카드 (핵심)

| 상태 | 추천 판본 카드 내용 | 다운로드 버튼 |
|---|---|---|
| **바로 받기 가능** (추천 판본 있음 + 파일 있음 + FREE) | §3-2 전부 | `PDF 받기 · 2.4MB` 활성 |
| **준비 중** (추천 판본 없음 / 파일 없음) | 카드는 유지하되 내용을 바꾼다: 라벨 `추천 판본` 없음. 아이콘 `hourglass_empty` 40px `--color-text-disabled` + 제목 `악보를 준비하고 있어요` (`--font-size-lg`) + 보조 `IMSLP 원본 페이지에서 먼저 볼 수 있어요` (`--font-size-md` muted) + `.btn.btn-outline` `IMSLP에서 보기 ↗` (곡의 IMSLP 작품 페이지, 새 탭; 링크조차 없으면 버튼 생략). 곡 정보 영역은 전부 보임. 추천 판본이 있는데 파일만 없으면 판본 정보(종류·출판사 등)는 위 문구 아래 `--font-size-sm` 로 표시 | **없음** |
| **한국에서 이용 제한** (추천 판본 RESTRICTED) | §3-2 에서 미리보기·판본 정보·뱃지·출처는 그대로. 버튼 자리에 InlineAlert **warning** 없이 **restricted 톤**(`--badge-restricted-*` 색): `한국 저작권 기준으로 아직 자유 이용이 어려운 판본이에요. IMSLP 원본 페이지에서 각자 판단해 이용해 주세요` + `.btn.btn-outline` `IMSLP에서 보기 ↗` | **없음** |
| **저작권 확인 중** (추천 판본 UNKNOWN) | 위와 같되 InlineAlert **warning**: `이용 가능 여부를 확인하는 중이에요` + `IMSLP에서 보기 ↗` | **없음** |
| **추천 판본은 제한/확인 중인데 다른 판본에 바로 받기 가능이 있음** | 위 카드 아래에 InlineAlert **info**: `바로 받을 수 있는 다른 판본이 1개 있어요 — 보기` ("보기" `.btn.btn-text`) → 클릭 시 "다른 판본 보기" 펼치고 그 행으로 스크롤. 진입 시 **자동 펼침** | 추천 카드엔 없음, 해당 행에 `PDF 받기` |
| **미리보기 없음** (파일은 있음) | 회색 자리 `미리보기 준비 중`. 라이트박스 열리지 않음(클릭 불가, 커서 기본) | 활성 |
| **파일 20MB 이상** | 큰 파일 경고 한 줄(§3-2). 확인 창 없음 | 활성 |

### 동작·통신 상태

| 상태 | 표시 |
|---|---|

| **라이트박스 이미지 실패** | 캡션 자리에 `미리보기를 불러오지 못했어요` + 닫기 |

## 플랫폼 차이

- 앱 미도입.
- 모바일: 미리보기 폭 100%(최대 320px), 버튼 폭 100%, 큰 파일 경고는 버튼 아래. 다운로드는 브라우저 기본 동작(내려받기 또는 새 탭 PDF) — 별도 안내 없음.
- 데스크톱: 미리보기 240px 좌측, 버튼 최소 240px, 경고는 버튼 오른쪽.
- 라이트박스: 모바일 핀치 줌은 브라우저 기본.
