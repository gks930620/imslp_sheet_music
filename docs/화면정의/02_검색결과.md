## 구성 요소

| 요소 | 문구 / 동작 | 토큰 / 재사용 |
|---|---|---|
| 검색창 | SearchBar large. URL `q` 값이 채워진 상태. 고쳐서 Enter → `q` 갱신, `page`·필터는 **초기화**(새 검색). `✕` 로 비우기 | 공통 |
| 작곡가 일치 카드 | `작곡가: 쇼팽 (Frédéric Chopin)` 굵게 / 아래 `곡 24개` / 오른쪽 `chevron_right`. 카드 전체 → `/composers/:id`. 검색어가 작곡가 한글·원어·별칭에 걸릴 때만. 여러 작곡가에 걸리면 세로로 최대 3개(넘으면 `작곡가 N명 더 — 작곡가 목록에서 찾기` 링크) | 흰 카드 `--radius-md`, **좌측 4px 띠 `--color-primary`**, 아이콘 `person` `--color-primary`, padding `--space-4`. 아래 `--space-4` |
| 결과 건수 | `'녹턴' 검색 결과 21곡`. 필터가 걸려 있으면 `'녹턴' 검색 결과 21곡 중 8곡` | `--font-size-base` `--font-weight-medium`, 검색어 부분 `--color-primary` |
| 필터 바 | FilterBar (00 §3-13). 난이도 복수 → `level=BEGINNER,ELEMENTARY`, 쪽수 단일 → `pages=LE10|11_20|GE21`, 체크 → `downloadable=true`. 바꾸면 즉시 재조회 + `page=0` | 공통. 난이도 칩 `title` 에 한 줄 기준 |
| 곡 목록 | WorkCard ×20 (00 §3-2). 별칭 일치 줄은 **서버가 내려주는 "걸린 별칭"** 을 그대로 `'{별칭}'으로 찾음` — 대표 제목/작곡가/작품번호로 걸린 항목은 줄 없음 | 기존 `.post-list` 카드 |
| 페이지 이동 | 기존 `Pagination`. 클릭 → `page` 갱신 → 스크롤 맨 위 | 기존 |
| 브라우저 뒤로가기 | 라우터 히스토리에 검색·필터·페이지가 각각 남아야 직전 상태로 돌아간다 (`push`, `replace` 아님) | — |

정렬은 서버(일치도 → 다운로드 수). 화면에 정렬 선택 UI **없음**.

## 상태별 UI

| 상태 | 표시 |
|---|---|
| **로딩** | 검색창·필터 바는 즉시 렌더(필터는 조작 가능하되 결과 갱신은 응답 후). 건수 자리 스켈레톤 1줄, 목록 스켈레톤 카드 5개 |
| **결과 0건 (검색어 자체가 안 맞음)** | 필터 바 숨김. `.empty-state` 아이콘 `search_off`: 제목 `'ㅁㄴㅇ'에 맞는 곡을 찾지 못했어요` / 보조 3줄(불릿 없이 각 줄): `다른 이름으로 불리기도 해요 — 예: 월광 / Moonlight / Op.27 No.2` · `작곡가 이름으로 찾아보세요` · `1차는 피아노 독주곡만 있어요` / 아래 `인기곡` 소제목 + WorkCard compact 5개 / `.btn.btn-outline` `작곡가 목록 보기` → `/composers` |
| **필터를 걸었더니 0건** | 필터 바 유지(선택 상태 보임). 목록 자리에 `.empty-state` 아이콘 `filter_alt_off`: 제목 `이 조건에 맞는 곡이 없어요` / `.btn.btn-secondary` `필터 해제` → 필터 쿼리 제거, `page=0` |
| **빈 검색어** (`q` 없이 진입) | 홈으로 보내지 않고 이 화면에 머묾: 검색창 포커스 + 안내 `찾고 싶은 곡 이름, 작곡가, 작품번호를 입력해 주세요` (`--color-text-muted`, `.empty-state` 아이콘 `search`). 목록·필터 없음 |
| **불러오기 실패** | 검색창은 살아 있음. 목록 자리에 `연결을 확인해 주세요` + `다시 시도` (00 §3-9) |
| **작곡가 카드만 있고 곡 0건** (예: 작곡가는 있는데 공개 곡 없음) | 작곡가 카드 표시 + 아래 결과 0건 빈 상태 |
| **페이지 번호가 범위 밖** (`page=99`) | 서버가 빈 목록 → `이 페이지에는 곡이 없어요` + `.btn.btn-text` `첫 페이지로` |
| **준비 중 / 이용 제한 / 확인 중 곡** | 카드 제목 오른쪽 상태 뱃지. 쪽수는 추천 판본 있을 때만 |
| **한국어 제목 없는 곡** (수집 직후) | 카드 제목 자리에 원어 제목(같은 굵기), 원어 줄 생략, 뱃지 "준비 중" 또는 "저작권 확인 중" |

---

## 플랫폼 차이

- 앱 미도입.
- 모바일: 필터 바 가로 스크롤 1줄, 오른쪽 끝 흐림(`linear-gradient` to `--color-bg`)으로 더 있음을 표시. 데스크톱: 한 줄 펼침.
- 모바일: 곡 카드 상태 뱃지는 제목 아래 줄로 내려감(제목이 잘리지 않게).
